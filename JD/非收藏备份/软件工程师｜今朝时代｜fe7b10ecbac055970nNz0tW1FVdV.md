# 电池软件工程师（BMS方向）
**岗位名称：** 电池软件工程师 / BMS软件工程师  
**所属⾏业：** 锂电池 / 储能 / 房车电池 / ⼯业电池  
**⼯作地点：** 深圳  
**经验要求：** 2年以上相关经验优先  
**学历要求：** 大专及以上，本科优先
## 岗位职责
1. 负责锂电池产品的软件开发、调试及维护，重点包括 **BMS相关软件功能开发与系统集成**。
2. 配合BMS供应商或硬件工程师完成：
   - SOC / SOH 数据读取与处理
   - 单体电压、总压、电流、温度等数据⾤集
   - 充放电状态及故障状态判断
   - 过充、过放、过流、短路、高低温等保护逻辑联调
   - 均衡、休眠、唤醒等功能验证
3. 熟悉并能够进行 **CAN、RS485、UART、Modbus、Bluetooth等通信协议**的开发、解析和调试。
4. 负责BMS与以下设备或系统之间的通信对接：
   - 手机APP
   - PC上位机
   - 逆变器
   - MPPT
   - DC-DC充电器
   - EMS
   - Victron等第三方能源设备
5. 根据产品需求定义通信协议、数据格式、故障码及设备接口。
6. 配合硬件、测试和产品团队完成锂电池系统功能测试、异常测试及问题定位。
7. 对实际电池运行数据进行分析，为SOC、SOH、电池健康状态、剩余使用时间等算法提供数据支持。
8. 参与智能锂电池产品开发，包括：
   - 电池剩余运行时间预测
   - 异常耗电检测
   - 电池健康状态分析
   - 故障预警
   - 用户用电数据分析
9. 编写和维护相关技术文档，包括：
   - 通信协议
   - 软件需求说明
   - 测试文档
   - 接口文档
   - 软件版本记录
## 任职要求
1. 电子、自动化、计算机、通信、电气工程等相关专业。
2. **了解锂电池BMS基本工作原理，有BMS软件开发、调试或协议对接经验。**
3. 熟悉以下一种或多种开发语言：
   - C / C+1分析及电池预测算法**相关产品开发。
