## 职位描述

岗位职责
1、跨平台客户端架构主导：主导 Windows / macOS 双平台客户端/上位机软件的整体架构设计——制定技术选型与架构决策（ADR）、主导模块划分与跨平台抽象层建设，屏蔽系统差异（文件系统、进程、USB/串口、UI 渲染等），治理技术债，规划架构长期演进路线。
2、芯片配置与调试工具攻坚：主导对接显示/视频处理芯⽚的寄存器配置、参数烧录、板级联调、状态监控等 PC 端调试⼯具的⽅案设计与核心实现，与固件/硬件团队共同定义通信协议与接口规范。
3、设备控制与数据采集平台：主导设备控制指令体系与实时数据⾤集、解析、可视化、日志追溯与分析能力建设，定义并守住性能与可靠性指标（吞吐、时延、长时间运行稳定性）。
4、产品演示与产测工具体系：主导面向客户演示与产线测试场景的软件体系，推动产测自动化覆盖率与产线效率提升，缩短「芯片能力 → 客户感知」的距离。
5、工程化与质量体系建设：负责安装包制作、自动更新、崩溃收集与分析（Crash 上报、符号化、归因），持续优化启动速度、内存与渲染性能，建立代码规范、CI/CD、单元测试与自动化测试体系并推动落地。
6、技术带领与人才培养：负责客户端方向的技术规划与任务拆解，指导初中级工程师成长，主导技术评审与方案评审，沉淀文档、组件与最佳实践。
7、AI 提效与研发范式升级：推动 AI 编程工具在团队常态化落地（代码生成、调试辅助、测试与文档补全、问题定位），沉淀可复用的提示词库与工作流，建立提效度量与分享机制。

3、跨平台架构主导能力：具备 Windows + macOS 双平台客户端从 0 到 1 的架构与落地经验，深入理解两套系统的 API 差异、编译链（MSVC / Clang）、签名与发布流程；能输出架构决策文档，主导模块与子系统设计，对可扩展性、可维护性与长期演进负责。
