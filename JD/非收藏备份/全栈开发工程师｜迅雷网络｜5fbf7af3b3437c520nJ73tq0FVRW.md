## 职位描述

岗位职责：
1. 负责业务系统的 Java 后端开发，以及相关前端页面和交互功能开发，覆盖后台管理、业务运营和数据报表等场景。
2. 独立负责中等复杂度业务模块，完成需求澄清、任务拆解、接口与数据库设计、前后端开发、联调测试和上线支持。
3. 在团队架构和研发规范下制定模块技术方案，合理处理业务边界、异常场景、数据⼀致性和可维护性问题。
4. 完成权限控制、参数校验、异常处理、⽇志记录、事务和幂等处理，保障功能正确性与系统稳定性。
5. 主动排查和解决线上问题，开展 SQL、接口和业务流程优化，并对问题进⾏复盘。
6. 与产品、测试、运维及业务团队协作，识别需求中的不明确事项和交付风险，及时推动解决。
7. 编写必要的接口文档、测试用例和发布说明，参与代码评审，并为初级 Java ⼯程师提供开发指导。
8. 熟练使用 AI 工具辅助开发、测试和排障，并对生成代码的正确性、安全性和可维护性负责。
岗位要求：
1. 本科及以上学历，计算机及相关专业优先；具备 3–6 年软件开发经验，重点考察实际项目能力和独立交付经验。
2. 熟练掌握 Java、Spring Boot，理解常用集合、异常处理、并发及 JVM 基础，具有实际业务系统开发经验。
3. 熟悉 MySQL，能够独立设计业务表结构、编写复杂 SQL，理解索引、事务、锁和慢 SQL 优化。
4. 熟悉 Vue 或 React、TypeScript，能够独立完成中后台页面、表单、权限交互和接口联调。
5. 能够独立负责完整业务模块，合理拆解任务和评估工作量，主动处理交付过程中的问题与风险。
6. 理解缓存、消息队列和异步任务的常见使用场景；能够结合业务处理幂等、重试和数据一致性问题。
7. 具备线上问题排查能力，能够通过日志、数据库和接口链路定位问题，并推动解决。
8. 熟悉 Git、Maven、Docker 和 Linux 常用操作，了解 CI/CD、发布及回滚流程。
9. 具备良好的沟通协作能力和责任心，能够主动推动跨团队协作，并为初级工程师提供技术支持。
10. 具备金融行业或金融科技业务系统的实际开发经验，参与过支付、跨境金融、信贷、资金、风控、清结算或对账等至少一种业务场景；能够说明本人负责的模块、核心业务流程及关键问题的处理方式。有跨境金融相关经验者优先。
