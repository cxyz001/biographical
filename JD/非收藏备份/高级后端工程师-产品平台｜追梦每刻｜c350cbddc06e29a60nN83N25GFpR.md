## 职位描述

【团队使命】 
WiCi 是聚焦下一代个人AI与无线GPU计算的早期硬科技公司，核心团队由清华⼤学、⾹港科技⼤学科研与工程人才组成。我们专注解决计算机底层系统、⽹络、大模型等核心技术问题，自研全新形态AI硬件，并自主搭建全平台软件生态，构建面向个人AI时代的无线算力底层基础设施。
我们希望你是愿意深度参与产品从0到1、兼具技术攻坚能力与产品思辨力的全栈型创造者。在这里你将直接对接创始人与核心研发团队，从早期产品构想、交互定义到多端落地迭代，全程参与技术决策与体验优化。
我们期待热爱创造、乐于持续学习，思维开放的工程师的加入。
【岗位职责】
- 负责产品平台的后端与设备服务，包括设备发现与配对、身份认证、权限、任务提交、任务状态和结果管理。
- 设计和维护客户端与 Box 之间的 HTTP、WebSocket 等接口，以及必要的 TypeScript SDK，保证接口清晰、稳定并具备版本兼容能力。
- 建设长时间任务执行机制，支持任务持久化、幂等、取消、超时、重试、断点恢复和故障后的状态恢复。
- 负责文件与数据流转，包括上传、下载、缓存、结果保存、访问权限和本地数据隔离。
- 设计 SQLite 或 PostgreSQL 数据模型，负责数据库迁移、备份恢复和数据一致性。
- 负责 Linux 环境下的服务部署、更新、日志、监控、诊断和基本运维能力。
- 与客户端工程师、GPU／系统工程师和产品负责人完成端到端联调，定位设备连接、任务执行、性能、稳定性和数据一致性问题。
- 将真实用户反馈转化为可交付的产品改进，优先解决用户无法完成任务、任务失败后无法恢复、结果难以找到等问题。
- 参与技术方案评审、代码审查和任务拆解，并帮助学生成员将原型代码逐步转化为可维护的产品代码。
- 在需求尚未完全明确时，识别关键不确定性，控制实现范围，优先交付一个完整可用的用户流程。

- 熟练掌握 TypeScript 和 Node.js，熟悉至少一种后端框架。
