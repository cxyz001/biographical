## 职位描述

工作职责：
1、设计并实现 AI Agent 的核心机制：任务规划、工具调用、记忆与上下⽂管理、多轮对话、能⼒编排等。
2、结合 RAG、向量检索、多模态模型，构建能理解图像/视频内容的智能体。
3、负责智能影像业务的后端服务开发，包括 API 设计、并发处理、数据存储、权限校验、⽇志追踪等。
4、将大模型、多模态模型、第三方 AI 服务等组件⼯程化封装，保障服务稳定、可观测、易扩展。
5、参与系统架构设计，提升性能与可维护性，解决关键链路中的一致性与异常问题。
6、与产品、算法、前端、测试团队紧密配合，让 AI Agent 能力在真实影像场景中跑起来、跑得好。
任职要求
1、本科及以上，计算机、软件工程、AI、电子信息、自动化等相关专业优先。
2、熟练掌握 Java 或 Go，后端基础扎实：懂 API、并发、缓存、消息队列、数据库，也会打日志、做监控。
3、有 AI Agent / LLM 应用 / RAG / 工作流编排 / 多轮对话 等实战经验，不只是调过 API。
4、具备具体影像行业经验：安防视频、医疗影像、工业视觉、智能硬件摄像头、短视频、直播、车载影像、影像内容审核等方向。
5、熟悉 MySQL、PostgreSQL、Redis 等基础设施，有高并发或分布式经验更佳。
6、代码有洁癖：注重模块边界、接口设计、异常处理、单元测试。
7、善于拆解问题，能沟通、能协作，能理解业务而不是只接需求。
