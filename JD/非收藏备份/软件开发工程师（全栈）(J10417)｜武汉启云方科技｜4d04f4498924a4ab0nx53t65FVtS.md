## 职位描述

工作职责:
1.负责医疗设备物联网、医疗售后服务信息化、动物医疗信息化及互联网医疗服务等方向的系统架构设计与全栈开发；参与市场调研、⽤户需求分析与产品规划，梳理核⼼业务流程，输出技术⽅案，推动医疗云平台子系统高质量落地。
2.独⽴完成前后端开发工作：前端熟练运用 HTML、CSS、JavaScript 及 Vue/React 等主流框架，实现页面布局、交互效果与响应式适配；后端负责服务端接口、业务逻辑与数据库设计开发，完成前后端接口联调，保障系统性能、兼容性与用户体验，高效解决开发过程中的技术问题。
3.深刻理解业务目标与用户诉求，以数据为依据开展产品迭代验证，结合用户反馈与系统运行数据，持续优化产品功能与前后端实现方案；合理运用 AI 辅助编程工具提升开发效率与代码质量。
4.主动衔接产品设计与技术实现，将产品需求精准转化为可执行的前后端开发任务，降低跨职能沟通成本；与产品、运营、后端、测试等团队紧密协作，保障项目进度与交付质量。
任职资格:
1.5 年及以上互联网或医疗信息化领域工作经验，具备平台级系统的前后端全栈开发能力；具备 APP、数据平台类产品的全流程设计与开发经验者优先；熟悉主流 AI 辅助编程工具（如 Cursor、Claude Code 等）并能有效应用于实际开发场景。
2.具备扎实的软件工程能力与产品思维，能基于数据分析提出迭代优化方案；拥有医疗信息化领域经验者优先，包括但不限于医院信息系统（HIS）、实验室信息系统（LIS）、体外诊断（IVD）相关业务场景。
3.精通 HTML、CSS、JavaScript，熟练掌握 Vue 或 React 至少一种主流前端框架，了解前端工程化与模块化开发规范；精通至少一门后端语言（如 Java、Node.js、Python、Go 等）及常用后端框架，熟悉 MySQL/PostgreSQL 等关系型数据库及缓存、消息队列等中间件；具备独立完成前后端开发、接口联调及问题排查能力，具备基础的系统性能优化意识与实践。
4.熟悉 RESTful API 设计、前后端分离架构，了解微服务、容器化（Docker）等部署方案；具备将产品方案快速转化为可落地代码的能力。
5.思维逻辑清晰，具备优秀的书面表达与跨团队沟通协调能力；责任心强，结果导向，能适应医疗科技领域业务快速迭代的工作节奏。
6.认同技术驱动产品创新的理念，具备持续学习新技术、新工具的主动性，能结合业务实际合理评估并应用 AI 辅助开发工具提升效能。
