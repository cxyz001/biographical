## **职位名称：全栈工程师（Fullstack Engineer – NestJS / NextJS）**
### **职位概述**
我们要打造的是一条面向真实资产（RWA）与支付场景的 Layer2 区块链，连接合规⾦融与链上⽣态。我们正在寻找⼀位兼具后端架构能力与前端实现能力的 **全栈⼯程师**，参与构建新一代合规金融基础设施。
该职位以 **NestJS / NextJS** 为核心技术栈，偏重后端开发与系统集成，同时要求具备一定的前端工程化能力与产品感。
---
### **工作职责**
* 参与 **平台核心服务** 的设计与开发，包括账户、资产、合规、清算、以及多链交互模块；
* 负责 **API 设计与系统集成**，确保多模块之间的稳定通信与数据一致性；
* 搭建与维护 **全栈开发框架**（NextJS + NestJS），确保良好的代码结构与工程效率；
* 参与区块链交互层逻辑设计，包括钱包、签名、事件订阅与资产同步；
* 参与平台管理后台、控制台等 Web 界面的实现，优化前后端联动体验；
* 持续优化系统性能、安全性与可观测性；
* 与产品、区块链、DevOps 团队协作，推进从业务需求到技术交付的全流程。
---
### **任职要求**
**核心技能**
* 熟练掌握 **TypeScript / NestJS / NextJS / React**，能独立完成后端接口与前端组件开发；
* 理解 **微服务架构 / 事件驱动 / 消息队列** 的设计理念；
* 熟悉 **PostgreSQL / Prisma / Redis / Docker** 等基础设施；
* 有良好的 **API 设计与数据建模能力**；
* 理解 **区块链基本原理**：钱包交互、智能合约调用、交易事件监听；
* 掌握 **CI/CD 与代码质量管理**（GitHub Actions / Cloud-native 环境）；
* 英文文档阅读与问题定位能力强。
