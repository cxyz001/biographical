## 职位描述

一、岗位定位
负责公司SaaS 系统与低代码平台后端服务设计、开发与优化，支撑可配置化、多租户、高可用、可扩展的后端架构，保障平台稳定、高效、安全运行，是业务迭代与架构落地的核心骨干。
二、岗位职责
1. 业务开发：参与低代码平台与 SaaS 产品后端开发，包括表单引擎、流程引擎、权限体系、数据模型、API 服务、集成网关等核心模块。
2. 架构与设计：参与需求评审与技术方案设计，编写清晰可维护的接口与服务设计文档，保证代码质量、可扩展性与可测试性。
3. API 与集成：负责后端接口设计与实现，支持前端 / 移动端 / 第三方系统对接；负责开放 API、WebHook、外部系统集成对接。
4. 数据与存储：负责数据库设计、SQL 优化、索引优化、数据同步与 ETL；处理高并发、大数据量场景下的性能与稳定性问题。
5. 质量保障：编写单元测试 / 接口测试，参与 Code Review，推动工程规范、CI/CD 与自动化部署落地。
6. 问题与优化：线上问题快速定位与排查，持续做性能优化、稳定性优化、日志与监控完善，提升系统可用性。
三、任职要求（中级）
1、基本条件
- 本科及以上学历，计算机相关专业，3–5 年服务器端开发经验
- 熟练使用 Python 或 Go 任一语言（会两者优先），具备良好工程习惯与编码规范
- 有 SaaS / 低代码 / 零代码 / BPM / 表单引擎 任一相关项目经验优先
2、技术要求（核心）
- Web 框架
  - Python：熟练使用 FastAPI / Django / Flask 至少一种
  - Go：熟练使用 Gin / Fiber / GoFrame 至少一种
- 数据库与缓存
  - 熟练使用 MySQL/PostgreSQL，能独立设计表结构、编写优化 SQL、处理事务与锁
  - 熟练使用 Redis 做缓存、分布式锁、限流、计数器等场景
- API 设计：熟悉 RESTful API 设计，了解 OpenAPI/Swagger，有接口版本管理、权限、签名、限流经验
- 中间件与服务：熟悉消息队列（RabbitMQ/Kafka）、定时任务、ElasticSearch（加分）、MinIO（加分）
- 部署与运维基础：熟悉 Linux、Git，了解 Docker，有 CI/CD（Jenkins/GitLab CI）使用经验
- 多租户与 SaaS：理解 SaaS 多租户架构（共享库 / 隔离库）、数据权限、灰度、租户隔离机制优先
3、能力与素质
- 能独立完成需求分析、接口开发、联调、上线与复盘
- 具备良好问题排查能力，对性能、稳定性、安全有敏感度
- 良好沟通与协作，能与产品、前端、测试高效配合
- 有低代码平台（表单 / 流程 / 报表 / 权限）相关业务理解优先
