⼀、岗位名称
Java 后端开发⼯程师
⽅向：物联网平台 / SaaS 系统 / 工作流引擎 / 设备数据处理
⼆、岗位职责
1.	负责公司物联网 SaaS 平台后端系统的设计、开发与维护，包括设备接入、设备管理、告警管理、工单流转、数据统计、权限管理等核心模块。
2.	参与工作流相关业务建设，包括审批流、派单流、维保流程、告警处理流程、任务流转、状态机等功能设计与开发。

4.	参与 SaaS 多租户架构设计，支持不同客户、项目、组织、角色、权限、配置的隔离与管理。
5.	负责后端接口设计与开发，配合前端、移动端、边缘设备端完成业务联调。
6.	参与系统性能优化，包括数据库索引优化、接口响应优化、异步任务处理、消息队列削峰、日志与监控优化等。
7.	编写清晰、可维护的代码，参与技术方案评审、代码 Review、接口文档编写和线上问题排查。
8.	根据业务发展，参与平台架构升级，包括微服务拆分、消息队列、缓存、定时任务、工作流引擎、设备通信协议等技术方案落地。
