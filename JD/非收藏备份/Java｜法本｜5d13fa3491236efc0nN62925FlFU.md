## 职位描述

岗位职责
1.负责智慧食堂核心模块的开发与维护，以及食品安全平台建设。
2.参与需求分析、技术方案设计、任务拆分、编码实现、单元测试和发布验证，对负责模块的质量与交付结果负责
3.基于 Spring Cloud、OpenFeign、Gateway、Nacos、Sentinel 等完成服务治理，并维护微信端、⼩程序、消费设备及银⾏/⽀付渠道等系统接口。
4.处理支付结算链路中的事务一致性、幂等、并发、重试、消息补偿和异常对账，落实 RBAC 权限及单位/商户维度的数据隔离。
5.负责线上问题定位、SQL/JVM 性能优化、⽇志监控、定时任务和消息队列排障，参与代码评审、技术文档、版本发布及故障复盘。
任职要求
1.本科及以上学历，计算机、软件工程等相关专业，具有 3-5 年 Java 开发经验，能够独立负责复杂业务模块。
2.熟练掌握 Java 8、集合、并发、IO、异常处理和 JVM 基础，熟悉 Spring Boot、Spring MVC、Spring Cloud、Gateway、OpenFeign 等技术。
3.熟练使用 MySQL、MyBatis/MyBatis-Plus、Redis、RabbitMQ，理解索引、事务、锁、缓存一致性、消息幂等、重试及 SQL 优化。
4.理解 OAuth2、RBAC、多租户/多商户数据隔离，熟悉 RESTful API、JSON、文件导入导出及第三方系统集成，对支付、退款等敏感链路有较强安全意识。
5.熟悉 Maven、Git、JUnit、Linux、Docker 及常用调试工具，具备代码评审、日志分析、性能排查能力，并有 AI 大模型协同编程经验。
6.熟悉 Redis、RabbitMQ，理解缓存一致性、消息幂等、重试、去重和定时任务；了解 Nacos、Sentinel、XXL-JOB等开源组件。
有智慧食堂、食品安全监管、明厨亮灶、后厨巡检、检验检测、食材追溯或风险预警平台经验者优先；具备消费设备、物联网接入、数据一致性治理或复杂故障应急经验者优先。
