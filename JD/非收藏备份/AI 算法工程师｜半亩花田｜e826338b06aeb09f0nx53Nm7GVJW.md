## 职位描述

岗位职责
1. 实现AI算法在游戏卡牌鉴定中的落地，包括环境接入、训练流程优化、算法效果优化、模型能力评估等方面内容；
2. 使⽤强化学习、模仿学习等算法优化AI的鉴定效果，提升客户体验；
3. AI 驱动开发：以 Vibe Coding 为主要开发⽅式，⾼效完成业务模块的开发、测试和发布；
4. AI初审查：负责审查和优化 AI 生成的代码，确保其质量、性能和安全性符合⼯程标准；
5. AI 全栈应⽤开发：负责大模型等相关能⼒的设计与开发，完成 AI Agent、智能工具及业务系统等应⽤的落地；
6. 主导评级系统中“AI 自动评分”模型的研发，包括数据预处理、模型训练、调优与部署；
7. 针对卡牌实物，研发图像识别、边角磨损检测、表面划痕检测、居中度分析等算法；
8. 与后端团队协作，将 AI 模型工程化落地，提供高可用的 API 接口。
岗位要求
1. 本科及以上学历，计算机视觉、人工智能相关专业，5-10年以上开发经验，至少1年及以上AI agent&AI全栈开发经验；有游戏/电商/交易/后台系统等工作经验更佳；
2. 掌握AI全栈技术栈：后端Java/Go/Python、前端Vue/React、大模型API接入等；
3. 对机器学习、强化学习、深度学习等算法原理及其在互联网⾏业的应用有深入的理解和浓厚的兴趣；
4. 基础扎实，编码过关，熟悉常用的算法和数据结构，熟练掌握C/C++、go、Python等至少一门编程语言，具备较强动手和快速学习能力，能够应用主流框架实现模型搭建与算法调优；
5. 对于游戏卡牌鉴定的AI技术研究探索和应用有浓厚兴趣的优先，有卡牌质检、瑕疵检测或复杂图像识别落地经验者优先；
6. 熟练使用 Cursor、Codex, Claude Code 等，有使用 AI 独立完成 Web 全栈项目（从 0 到 1）的实战经验；
7. 热爱游戏行业，了解游戏研发流程（美术/策划/程序工作链路）者优先，对AI赋能游戏内容生产有浓厚兴趣和探索欲。
