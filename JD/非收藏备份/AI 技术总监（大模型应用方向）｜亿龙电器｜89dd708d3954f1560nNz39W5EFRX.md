## 职位描述

关于我们正在做的事情——
我们做的不是又一个聊天机器人，而是⼀个能感知、能记忆、能主动⾏动的 AI 伙伴：多模态交互、长期记忆、情绪感知、⼈设稳定，主动解决用户在健康、睡眠、生活管理等真实场景中的具体问题。
【岗位职责】
1. 作为公司 AI 技术⼀号位，主导 AI 陪伴产品的整体技术架构，从 0 到 1 搭建算法、工程、数据团队，对模型效果、推理成本、线上稳定性三个指标负责；
2. 负责基座模型选型与微调体系搭建：
   - 基于业务场景对比选型开源基座模型（Qwen2.5 / DeepSeek-V3-R1 / Llama 3.x / GLM-4 等），在中文对话、角色扮演、推理能力、商用License之间做务实权衡；
   - 搭建 SFT / LoRA / QLoRA 微调流水线，沉淀角色人设模型、风格化模型、领域知识模型；
   - 主导 DPO / 偏好对齐数据构造与训练，解决人设漂移、答非所问、价值观跑偏等核心问题；
   - 训练框架可基于 LLaMA-Factory / Axolotl / DeepSpeed 等，按需自研数据构造与评测脚本。
3. 负责推理服务与成本优化：
   - 基于 vLLM / SGLang / TensorRT-LLM 搭建高并发推理服务，落地 PagedAttention、连续批处理、KV Cache 复用等优化；
   - 按场景做模型量化（GPTQ / AWQ / FP8）与路由策略：简单请求走小模型/蒸馏模型，复杂请求路由到大模型，把单位 Token 成本压下来；
   - 保障高并发对话场景下的延迟（首 Token 响应）与稳定性。
4. 负责对话核心引擎：
   - 设计长对话记忆系统：短期上下文窗口管理、历史摘要压缩、用户画像与长期记忆向量库（Milvus / Qdrant 等）；
   - 设计人设一致性控制方案：System Prompt 工程 + 角色 LoRA + 输出后处理三层兜底，解决多轮对话后人设崩、语气飘、失忆等问题；
   - 落地 Agent 能力：Function Call / Tool Use、主动对话发起、情景剧情推进、用户情绪感知与回应策略。
5. 负责多模态能力分阶段落地：
   - 语音链路：ASR（FunASR / Whisper 类）+ 情感 TTS（CosyVoice / GPT-SoVITS 类）+ 声音克隆，支撑语音陪伴；
   - 视觉链路：基于 Qwen-VL / GLM-4V 类多模态模型做用户图像理解、虚拟形象/场景图生成；
   - 按产品节奏排优先级，不一次性堆全部能力。
6. 负责 RAG 与知识库：
   - 搭建混合检索（向量+B M25）、Rerank 重排、Query 改写的完整链路，支撑角色世界观、产品知识、用户长期记忆的召回；
   - 治理召回质量，解决幻觉、张冠李戴、记忆错乱问题。
7. 负责评测与数据闭环：
   - 搭建自动化评测体系：基于 MT-Bench / AlpacaEval 思路自建陪伴场景评测集，覆盖人设一致性、情感恰当性、安全合规、对话流畅度四个维度；
   - 建立 Bad Case 回流机制：线上对话日志抽样 → 人工标注 → 沉淀为微调/偏好数据 → 模型迭代；
   - 建立灰度发布与 A/B 实验机制，用真实留存、对话轮次、时长等业务指标驱动模型迭代，而不是只看离线分数。
8. 负责 AI 安全与合规：敏感内容识别、越狱防护、未成年人模式、对话审计日志。
9. 招聘、培养和管理 3-8 人技术团队（算法、后端、数据），建立工程规范与 Code Review 机制。
【任职要求】
1. 本科及以上学历，计算机 / AI / 软件相关专业，5 年以上研发经验，其中 2 年以上团队管理经验；
2. 【硬门槛】有大模型应用从 0 到 1 上线的完整经历，亲手做过以下至少 2 件事：
   - 用 LLaMA-Factory / Axolotl / 原生 Transformers 跑通过 LoRA / SFT 微调并上线；
   - 用 vLLM / SGLang 部署过对外提供服务的模型推理集群，处理过并发与延迟问题；
   - 搭过生产级 RAG 链路，处理过召回质量、幻觉、长上下文问题；
   - 做过 Function Call / Agent 工作流并真正被用户使用。
3. 理解主流开源模型（Qwen / DeepSeek / Llama / GLM 系列）的能力边界、License 限制、中文表现差异，能根据业务选型而不是追新；
4. 熟悉 Prompt 工程、多轮对话状态管理、长上下文处理，理解"人设一致性"在真实 C 端对话里为什么难、怎么解；
5. 【加分项，有则优先】
   - 做过 AI 陪伴 / 虚拟角色 / 情感对话类产品（Character.AI、星野、猫箱、筑梦岛、Talkie 等方向），能讲清人均对话轮次、留存、时长等真实数据；
   - 落地过语音对话链路（ASR + TTS + 声音克隆）；
   - 搭过对话场景性。
