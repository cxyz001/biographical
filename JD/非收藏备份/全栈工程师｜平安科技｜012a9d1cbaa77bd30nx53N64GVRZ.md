## 职位描述

岗位职责
1. 参与需求评审，独立负责光伏储能 IoT APP 的移动端开发，基于 Flutter/Android/iOS 实现 APP 功能、交互开发，负责 APP 兼容性、性能优化、崩溃问题修复、应用商店上架迭代。
2. 独立开发 APP 配套后端服务：数据库设计、业务接口开发、MQTT 物联网设备对接、数据流转逻辑开发，⽀撑逆变器、⾤集器等硬件数据接⼊。
3. 负责 APP 客户端与服务端联调、问题定位，处理端到端链路故障；输出接口文档、技术文档，维护 Git 代码规范。

5. 持续优化 APP 和服务性能，跟进新技术预研，沉淀可复用组件。
 
任职要求：
1. 本科及以上，计算机相关专业；3–5 年开发经验，**同时具备移动端 APP 开发 + 后端服务开发实战经验。
2. 移动端：熟悉 Flutter 优先，熟悉 Android (Kotlin/Java) 或 iOS (Swift/OC)；熟悉 APP 打包、上架、热更新、性能调优。
3. 后端：熟练 Java SpringBoot 优先，熟悉 MySQL、Redis；了解 MQTT、Kafka 等物联网协议加分。
4. 可以独立完成整套 APP（客户端 + 后端接口）从开发、联调、上线到维护全流程；能看懂英文需求文档，有对接海外客户经验优先。
5. 熟悉敏捷开发，良好沟通能力，擅长独立排查线上疑难问题。
6. 加分项：光伏、储能、物联网 B 端 APP 项目经验、多语言海外 APP 开发经验。
