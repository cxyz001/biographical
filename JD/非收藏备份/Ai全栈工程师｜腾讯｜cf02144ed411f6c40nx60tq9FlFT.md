## 职位描述

关于我们
我们是 KOIBOT，总部位于东京，研发团队位于深圳，产品面向海外市场。
我们主要研发：
- ROLA 系列 AI 陪伴机器人；
- 机器人背后的 AI 底座 AMORIA，将对话、记忆、人格和情感表达整合在⼀起。
产品涵盖机器⼈端、云端服务和⼿机 App，已有线上用户和成熟的研发流程。接下来，AMORIA 将从机器人延伸到 App、⽹页及更多面向海外用户的 AI 应用。
团队拥有成熟的 AI 研发团队、海外投流团队和供应链资源。
我们的开发方式是“AI 写代码，人做架构和把关”：你将使用 Claude Code、Cursor 等工具拆解需求、让 AI 辅助实现，并负责代码审查、测试、上线和维护。
任职要求: 
1. 具有 3 年以上开发经验，独立上线过有真实用户使用的项目。
2. 熟练使用 Claude Code、Cursor、Copilot 等 AI 编程工具完成实际项目；面试时需现场演示 AI 开发流程。
3. 熟悉 Python，具备 FastAPI、Flask 或 Django 后端开发经验，熟悉数据库设计和 API 设计。
4. 具有大模型 API 接入经验，了解提示词设计、流式输出及调用成本控制。
5. 能够阅读、判断并修正 AI 生成的代码，具备良好的测试意识。
6. 愿意进行跨端开发：以后端为主，同时能够在 AI 辅助下修改 Flutter App，并配合 Android 机器人端联调。
岗位职责: 
1. 主导 AMORIA 新应用从 0 到 1 的开发：
   - 设计和封装后端服务及接口；
   - 接入大模型，根据产品规则生成英文、日文内容，支持多轮对话；
   - 开发会员订阅、免费额度、月付或年付、一键取消、个性化推荐及电商下单等功能。
2. 将新功能接入 AMORIA：
   - 使用 Python、FastAPI 开发云端服务，并部署至 Google Cloud；
   - 参与 Flutter 手机 App 开发；
   - 支持机器人端和 App 端调用相关功能。
3. 根据需要搭建面向海外市场的网页站，支持多语言、SEO 和 Stripe 支付；配合投流团队完成落地页、数据埋点和 A/B 测试。
4. 参与 AMORIA 其他模块的开发和维护，包括：
   - 服务端的对话、语音、情感和记忆功能；
   - App 功能迭代；
   - 机器人端联调。
5. 负责相关服务的部署和运维，保障系统稳定、安全，并确保用户数据合规存放在海外。
6. 使用 AI 工具进行开发，沉淀可复用的开发流程、提示词和技术文档。
加分项
- 具有 Flutter 或 Android（Kotlin）开发经验；
- 做过语音（TTS/ASR）、实时通信或智能硬件相关项目；
- 具有 Google Cloud 或 AWS 部署经验；
- 做过订阅制产品、出海应用或跨境电商，熟悉 Stripe、Shopify；
- 具备日语或英语能力；
- 拥有 GitHub 项目或已上线的 AI 应用。
