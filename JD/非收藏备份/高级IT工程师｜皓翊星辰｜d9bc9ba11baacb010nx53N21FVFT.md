## 职位描述

【岗位定位】
1、负责公司全球数字办公与企业 IT 体系建设，以提升员工协作效率、办公体验和组织效能为核心，重点推进企业协同平台、办公自动化、AI 办公应用、统⼀⾝份及 IT 服务体系建设。
2、岗位以数字办公与员⼯效能提升为主要方向，以企业 IT 能力为基础，保障账号、终端、办公⽹络等基础环境安全稳定，并推动公司从传统“IT 支撑”向数字办公与员工效能平台演进。
【我们希望你是】
一名懂 IT，但不局限于传统 IT 运维的人。有扎实的企业 IT 基础，也愿意深入员工真实工作场景，善于发现协作、流程和工具中的低效问题，并通过协同平台、自动化和 AI 持续改善员工体验和组织效率。我们更看重你是否能够让员工少做重复工作、减少系统摩擦、更高效地完成工作。
【岗位职责】
1、数字办公体系建设：规划并持续完善公司全球数字办公与企业 IT 体系，建立统一的工具、流程和服务标准，支撑全球团队安全、稳定、高效协作。
2、企业协同平台建设与运营【核心】：负责 Google Workspace、Slack、Notion、Jira/JSM 等平台的规划、集成和运营，持续优化沟通协作、知识管理和工作流程。（不仅负责账号和系统维护，更需要深入员工实际工作场景。包括不限 信息与知识协作方式、跨团队沟通与项目协作、工作流和审批流程、企业知识沉淀与检索、系统之间的数据和流程连接、工具使用规范、权限及成本）
3、办公自动化与 AI 效能建设【核心】：识别员工高频、重复和低效场景，通过 API、Workflow、AI Agent 等方式推动自动化和智能应用落地，提升员工与组织效率。（Workflow / API 自动化、AI 助手与 Agent、企业知识问答、IT 自助服务、跨系统流程自动化）
IT 服务与办公基础保障：负责员工账号、权限、终端、资产、办公网络及 IT 服务体系，推进 SSO、MFA、MDM、EDR 等能力建设，保障办公安全、稳定和合规。
4、企业软件与成本治理：管理企业 SaaS、软件许可证、供应商及预算，建立使用度量、续费、回收和成本优化机制。
【任职要求】
1、本科及以上学历，5 年以上企业 IT、数字办公、企业应用或内部效率平台相关经验。
2、对数字办公、企业协作及员工效率提升有较强理解，能够从实际工作场景发现问题并推动解决方案落地。
3、熟悉 Google Workspace、Slack、Notion、Jira/JSM 等主流企业协同平台，具备实际管理、配置或集成经验。
4、具备较强的系统集成与自动化能力，熟悉 API、Webhook、Workflow、脚本或低代码自动化中的一种或多种方式。
5、对 AI 在办公协作、知识管理和流程自动化中的应用有实际理解或落地经验，能够推动场景从需求到上线。
6、熟悉 SSO、MFA、账号权限、JML、MDM、终端、IT 资产及办公网络等企业 IT 基础能力，并具备良好的项目推进、跨部门协作和问题解决能力。
【优先条件】
1、有 SaaS、互联网、电商或全球化科技公司数字办公 / 企业 IT 经验。
2、有从 0 到 1 建设数字办公平台、企业协同体系、IT 服务台或内部效率平台的经验。
3、有 Google Workspace、Slack、Notion、Jira/JSM 等平台的深度治理、二次集成或自动化实践。
4、有 AI 办公、企业 Agent、Workflow Automation、RPA 等员工效率场景的实际落地经验。
5、参与过 SOC 2、ISO 27001、GDPR 等企业安全与合规建设。
6、能够使用英语进行日常工作沟通和跨区域协作。
