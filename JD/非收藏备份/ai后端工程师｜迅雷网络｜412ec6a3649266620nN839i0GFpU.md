## 职位描述

职位描述
我们正在招聘一名 Go 后端开发工程师，参与公司核心后端系统的设计、开发与持续优化。业务方向为 AI API 聚合与服务平台，产品形态类似 OpenRouter，需要对多模型接⼊、统⼀⽹关、鉴权计费、请求转发、稳定性治理等后端能力有较强理解。
本岗位为 中级岗位，要求候选人具备扎实的 Go 后端开发能⼒，同时 必须熟练使用 AI Coding 工具辅助研发。不会使用 AI Coding 工具，或无法将其融入日常开发流程的候选人，不予考虑。
岗位职责
1.负责公司核心后端系统的开发、维护与优化，使用 Go 完成高质量代码交付。
2.参与 AI API 聚合平台相关模块开发，包括但不限于：
多模型 / 多渠道接入
统一 API 网关
用户鉴权与权限控制
请求转发与路由策略
用量统计、计费、限流与风控
日志、监控、告警与稳定性治理
3.参与系统架构设计、接口设计、数据库设计及技术方案落地。
4.负责 MySQL / Redis 等基础组件的使用、优化与问题排查。
5.与前端、产品、测试、运维协作，推动需求高质量落地和上线。
6.负责线上问题定位、分析与修复，持续提升系统可用性、稳定性和可维护性。
7.在研发流程中高频使用 AI Coding 工具提升效率，并确保 AI 输出结果符合业务逻辑、工程规范与架构约束。
任职要求:
1.具备 2-5 年 Go 后端开发经验，能够独立承担中型模块开发工作。
2.熟悉 Go 语言，理解 goroutine、channel、context、并发控制、错误处理等核心机制。
3.熟悉常见后端开发模式，具备良好的接口设计、模块拆分和工程化能力。
4.熟悉 MySQL / PostgreSQL 中至少一种关系型数据库，能够独立完成表设计、SQL 编写、索引优化。
5.熟悉 Redis 常见使用场景，如缓存、分布式锁、计数、会话等。
6.熟悉 HTTP / HTTPS、RESTful API、JSON、鉴权机制等常见后端基础能力。
7.熟悉 Linux 开发环境，具备基础的日志排查和线上问题定位能力。
8.熟练使用 Git，具备良好的团队协作习惯。
9.具备较强的逻辑分析能力、问题解决能力和责任心。
AI Coding 要求（硬性要求）
1.必须熟练使用 AI Coding 工具，如 ChatGPT、Codex、Claude Code、Cursor 或同类工具。
2.能够使用 AI 辅助完成需求理解、技术方案分析、接口设计、代码生成、重构、自测辅助、文档整理等工作。
3.能对 AI 输出进行独立判断、审查和修正，而不是简单复制粘贴。
4.有成熟的 AI 协同开发习惯，能够在保证代码质量和架构一致性的前提下显著提升研发效率。
5.不会使用 AI Coding 工具，或无法将 AI 作为日常研发生产力工具者，不考虑。

2.有大模型 API 接入、多供应商统一封装、请求转发、路由调度等经验。
