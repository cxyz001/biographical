# Go 学习配套实验

配套教材：[Go 语言零基础到云原生实战](../02-Go语言零基础到云原生实战.md)。

## 运行

安装仍受官方支持的 Go 稳定版，在本目录执行：

```powershell
go test ./...
go vet ./...
go run .
```

服务地址为 `http://127.0.0.1:8080`。创建订单、查询、幂等冲突等操作见教材第 2、6 章。按 Ctrl+C 退出。

这是仅依赖标准库的本机教学服务：数据保存在内存，重启即丢失；不包含用户鉴权、真实支付、数据库、Redis、Kafka 或 Shopify 接入。教材后续章节提供这些项目的实现步骤、原理、失败场景与验收要求，需逐步自行完成。

## 已完成的验证

2026-10-23，Windows amd64、Go 1.27.3：

- `go test ./...`：通过，涵盖创建、重试、冲突、输入拒绝、并发幂等、并发上限、结果顺序、取消与下游错误。
- `go vet ./...`：通过。
- `go test -run '^$' -bench BenchmarkStoreGet -benchmem -count=1`：通过。本机单次结果 23.86 ns/op、0 B/op、0 allocs/op，仅代表内存查询微基准，不代表 HTTP 吞吐。
- `go test -race ./...`：未运行成功，工具提示需要 cgo；应在配置兼容 C 工具链后或支持的平台 CI 中补跑。

未执行真实数据库/消息队列集成测试、容器部署、Shopify 联调或完整服务压测。
