## 职位描述

岗位职责：
1、参与公司核心产品和业务模块的开发与迭代，能独立负责某个功能模块的前后端设计与上线。
2、在日常开发中使用 Claude Code、Cursor、GitHub Copilot 等 AI 编程⼯具，覆盖 API 设计、前端 UI 开发、后端逻辑实现及基础调试。
3、编写单元测试与集成测试，对 AI 辅助⽣成的代码做基础审查，确保符合规范、可维护。
4、与团队成员协作 code review，共同沉淀团队的⼯程规范与代码质量。
任职要求：
1、计算机或数学相关专业本科及以上，3-5 年全栈/后端/前端开发经验，有完整业务模块的端到端开发经历。
2、了解并使用过 Claude Code、Cursor、GitHub Copilot 等 AI 编程工具，能在⽇常工作中用 AI 提效（脚手架搭建、样板代码、基础调试等）。
3、掌握 Vue 或 React 等主流前端框架及 TypeScript，具备组件化开发经验。
4、掌握至少一门后端语言（Java/Go/Python 等），熟悉MySQL/PostgreSQL 等关系型数据库和 Redis 等缓存组件，能设计规范的 API。
5、有自测习惯，重视代码质量，能在团队 code review 中互相学习、共同提升。
加分项：
1、有 AI 编程工具的实际项目应用经验（如用 Claude Code 完成过完整需求、用 Cursor 写过组件等）。
2、了解大模型应用基础（提示词工程、AI Agent 概念等）者优先。
3、有技术博客、开源贡献者优先。
