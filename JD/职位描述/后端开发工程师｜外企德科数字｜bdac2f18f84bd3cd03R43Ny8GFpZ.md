## 职位描述

1.公司介绍-关于Zand
     Zand是数字资产的数字银行，高度关注加速阿联酋的数字经济，并为科技初创企业的银行业务提供支持。Zand 旨在改变阿联酋的银行业务方式，利用先进的数据功能、敏捷的运营模式和尖端技术的力量来增强客户体验。Zand 致力于安全性、可靠性和创新，是将数字资产集成到主流金融领域的领导者。
2.职位摘要-后端开发工程师：
      我们正在寻找一位高技能的后端开发人员，在金融科技或银行业具有深厚的背景，并在区块链系统开发方面拥有良好的业绩记录。理想的候选人将拥有深厚的金融系统知识、高级编程语言的专业知识以及创新思维，以帮助彻底改变金融格局。
3.主要职责
（1）设计、开发和维护可扩展的高性能数字资产管理系统。
（2）与跨职能团队合作，定义、设计和部署新功能和服务，重点关注高可用性、低延迟和可扩展性。
（3）通过代码审查、单元测试和系统优化，确保应用程序的性能、质量和响应能力。
（4）维护和增强现有系统架构，并为技术文档做出贡献。
（5）随时了解金融科技、银行和 Web3 领域的新兴趋势，尤其是区块链技术的进步。
（6）通过分享见解和最佳实践，为初级开发人员提供指导并增强团队知识。
（7）坚持安全最佳实践并遵守行业法规。
4.任职资格：
（1）计算机科学、工程或相关领域的学士或硕士学位。
（2）5-7年后端开发经验，金融科技、银行或Web3行业优先。
（3）熟练掌握Java和可选的C#（.NET）；
对 Spring Boot 或 Quarkus 等框架有深入的 Java 开发人员经验。
（4）具有RESTful API设计和开发经验。
熟练掌握容器化和编排技术，如 Docker 和 Kubernetes。
（5）熟悉微服务架构和利用 Kafka 等框架的事件驱动系统。
（6）熟练管理关系 （SQL） 和 NoSQL 数据库。
5.核心加分技能：
（1）了解特定于金融科技/银行应用的加密协议和安全措施。
（2）了解区块链技术，有相关项目的实践经验者优先。
（3）有智能合约开发经验，特别是使用Solidity等语言的经验，是一个加分项。
