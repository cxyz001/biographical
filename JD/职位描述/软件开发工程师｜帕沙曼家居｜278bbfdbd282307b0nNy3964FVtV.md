## 职位描述

岗位概述：负责公司信息化系统的二次开发与系统集成、外包开发质量管理，并协助 IT 经理推进 PLM、ERP、MES、OA、HR等业务系统的建设、深度应用与运维，支撑公司信息化及 IPO 内控建设需要。
工作职责：
1、负责公司内部系统的⼆次开发，包括报表开发、系统接口、落地⼩⼯具等，并运用 AI 编码工具提升开发与交付效率；
2、负责 CRM、ERP、MES、OA、HR、企业微信等系统之间的接口开发与联调，根据开发计划对接外包技术开发团队进⾏督办，推进系统间数据与流程贯通；
3、依据公司代码规范，对外包团队及厂商交付的代码与开发成果进行评审；
4、负责外包开发的技术方案评审、开发进度跟踪与交付验收；
5、建立并维护公司代码规范、开发文档与版本管理制度，使用 Git 进行版本管理、TAPD 进行开发计划管理；
6、协助 IT 经理开展信息化项目推广工作，参与 OA、ERP 等业务系统的立项、选型、实施与上线推广；
7、负责已上线业务系统的日常运维支持、故障处理与持续优化，保障系统稳定运行；
8、协助推进主数据统一与业务财务一体化，配合完成系统间数据核对与治理。
任职要求：
1、精通 Java、C#，熟悉 .NET / Spring 等主流开发框架，全日制大专及以上学历，具备 6 年以上实际开发经验；
2、精通 SQL，熟悉 SQL Server / MySQL / Oracle 等主流数据库，具备数据库设计与性能优化能力；
3、具备系统集成与接口开发经验（REST API、WebAPI、中间表等方式）；
4、有泛微 OA / 蓝凌 OA 平台，或鼎捷 / 金蝶 ERP 系统的建设、运维及二次开发经验；
5、熟练使用 Git 等版本管理工具，熟悉分支管理与代码评审流程；
6、熟练使用 TAPD 等开发计划管理工具；
7、熟练使用 Codex、CodeBuddy 等 AI 编码工具，具备 AI 辅助开发的实践经验；
8、具备代码评审能力，能够制定并推动落地代码规范与开发文档体系。
