## 职位描述

岗位职责：
1、toC端极致体验与高保真还原（核心）： 负责公司海外自建站（Shopify）的toC前端开发。贯彻移动端优先（Mobile-First）原则，完美还原设计师针对自⾏车及配件的⾼质感视觉设计；重点优化产品详情页、购物车及结账链路，通过极致的交互体验提升整站转化率（CRO）。
2、独⽴站前端极致性能调优： 针对自行车品类多图、多视频的特点，深度调优⽹站的核心网页指标（Core Web Vitals）。使用 Google Lighthouse、Chrome DevTools 等工具进行代码瘦身、动态加载及缓存优化，解决页面卡顿与臃肿，确保海外用户在各终端实现“秒开”体验。
3、toC转化链路与营销生态集成： 负责toC端各类营销App、评论系统、推荐算法插件的深度定制与二次开发；精准部署并调试 Google Analytics 4、Meta Pixel 等海外主流广告追踪像素，确保底层数据抓取的准确性，配合运营团队进行A/B测试。
4、日常维护与跨模式协同： 维护 Shopify Online Store 2.0 基础架构的安全与稳定；协助支撑现有的toB端（经销商门户）基础功能迭代，确保前端代码架构具备良好的兼容性与可扩展性。
任职要求：
1、3-5年及以上Web开发经验，兼有toB与toC的项目经验（以往经历中侧重toC端的性能与视觉交互），拥有完整的跨境电商独立站独立开发及上线案例。
2、熟练掌握 Shopify 平台机制，精通 Liquid 模板语言及 Schema 配置，熟悉 Shopify CLI 工具链，能够纯代码进行高难度的自研主题定制，拒绝单纯依赖插件堆砌功能。
3、熟练掌握 HTML5、CSS3 (Sass / Tailwind CSS / Flexbox / Grid) 以及 JavaScript (ES6+) / TypeScript。
4、精通至少一种主流前端框架（React.js 优先），对服务端渲染框架（Next.js / Remix）有实际开发经验或深度的原理认知。
5、至少掌握一种后端开发语言（首选最契合Shopify生态的 Node.js，或 Python / Go / PHP），具备实际的API接口设计、基础数据库交互或定制化中间件编写经验。
6、熟练掌握 GraphQL Storefront API、REST Admin API 及 AJAX API 接口，能够进行高性能、低延迟的前后端数据交互。
7、熟练使用 Git 进行版本控制；具备良好的英文技术文档阅读能力，有良好的代码注释习惯和团队协作能力。
