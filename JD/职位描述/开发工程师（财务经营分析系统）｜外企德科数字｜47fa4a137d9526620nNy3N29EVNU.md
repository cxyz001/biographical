## 职位描述

岗位简介
我们正在搭建面向中小制造、商贸企业的 AI 财务经营分析平台。系统对接 ERP、支持 Excel 导入，⾃动抓取业务 & 财务数据，⾃动核算经营指标，输出销售 / ⾤购 / 生产多维度经营分析报表，直接赋能企业老板与管理层做经营决策。现招聘开发⼯程师，负责该系统从 0 到 1 的研发落地。
岗位职责
负责财务经营分析平台后端开发，设计多源数据接入方案，对接金蝶云星空、用友等主流 ERP 系统，支持 Excel 批量导入财务、业务原始数据；
开发 ETL 数据清洗、数据建模模块，实现管理会计口径下复杂经营指标自动计算，自动生成分部门经营分析报表；
基于开源大模型做二次开发，落地 AI 辅助经营分析模块，实现数据解读、经营异常指标智能提醒；
数据库结构设计、API 接口开发，保障数据计算准确性、系统稳定性，负责测试、部署上线；
和财税业务专家对齐业务逻辑，拆解产品需求，持续迭代优化产品；
系统性能优化、数据权限设计，保障企业客户数据安全。
任职要求
本科及以上，计算机、软件工程、数据相关专业，3 年及以上 B 端开发经验；
熟练 Python（FastAPI/Django 优先）或 Java，精通 MySQL，能编写复杂 SQL，了解 PostgreSQL；
具备 ETL、数据清洗、第三方系统 API 对接经验，有 BI 报表、业财数据分析系统开发经历；
掌握数据建模，可落地复杂业务指标自动化计算逻辑；
熟悉 Linux 服务器、Git 版本管理，具备独立项目开发与上线能力；
良好业务理解能力，能够和财税专业人员沟通，理解经营分析、管理会计底层逻辑。
