## 岗位职责
1. 负责海外广告中台系统后端设计与开发，对接 Google、Facebook、TikTok、apple、Amazon 等第三方广告开放 API，实现账户管理、广告计划创建、启停、预算调整、批量操作等能⼒。
2. 开发⼴告事件归因、转化回传链路，处理曝光、点击、转化等海量埋点事件，完成实时数据统计，输出⼴告消耗、ROAS、CPI、CVR 等业务指标报表。
3. 负责广告数据流建设，完成广告平台数据拉取、数据清洗、数据存储，对接数仓，⽀撑运营、投放团队数据分析需求。
4. 保障系统高并发、高可用，处理 API 限流、重试、异常回调，解决第三方接口超时、数据延迟、权限等问题，保障海外业务稳定运行。
5. 参与系统架构迭代，优化性能，做接口、数据库、中间件调优；编写单元测试、接口文档，参与代码评审。
6. 和产品、投放运营、前端团队协作，理解出海广告业务，落地业务需求，跟进海外平台 API 版本更新，适配接口变更，处理业务故障。
7. 考虑海外多区域部署、海外数据隐私合规相关技术实现。

hive/spark开发和clickhouse/doris的开发，有海量日志、统计类系统开发经验加分。
3. 有第三方开放 API 对接实战经验；
须有 Facebook/Google/TikTok /twitter/apple/Amazon广告 API 对接经历。
4. 熟悉分布式系统，理解高并发、限流、重试、幂等设计，具备线上问题排查能力。
5.基础扎实，精通Java并发编程、JVM，理解网络通信、多线程等基础框架，对各种开源开发框架如Spring boot、kafka等开发体系有深入的应用。
6. 良好沟通能力，业务理解力强，抗压，能够跟随海外平台版本迭代做系统适配。
