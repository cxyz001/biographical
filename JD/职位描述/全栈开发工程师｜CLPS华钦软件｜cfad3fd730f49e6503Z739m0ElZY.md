## 职位描述

岗位职责
负责后端服务的设计、开发、维护及性能优化，主要技术栈为 Go、Python。
参与业务系统的接口设计、数据库设计、服务治理、日志追踪、任务调度等后端基础能力建设。
负责业务系统在腾讯云环境下的部署、发布、监控、告警、故障排查及稳定性保障。
参与腾讯云相关资源的日常运维和管理，包括 CVM、CLB、CDB、COS、CDN、云监控、安全组等。
使用 Python 或相关工具编写自动化脚本，提升部署、巡检、监控、数据处理及运维效率。
配合产品、前端、测试及业务团队完成需求评估、技术方案设计、开发联调和上线支持。
持续优化系统架构、服务性能、资源使用成本、安全配置和可用性。
任职要求
熟悉 Go 语言开发，有实际后端服务开发经验，能够独立完成接口、业务逻辑及服务模块开发。
熟悉 Python 开发，能够编写自动化脚本、工具脚本或后端服务。
了解腾讯云常用产品及运维实践，包括 CVM、CLB、COS、CDB、TKE、云监控、SSL/CDN 等。
熟悉 Linux 系统操作，具备常见线上问题排查能力，能够分析 CPU、内存、磁盘、网络、进程及日志等问题。
熟悉 MySQL、Redis、MongoDB 等常用数据库和中间件，具备一定的数据库设计、查询优化和缓存使用经验。
熟悉 HTTP、RESTful API、WebSocket、RPC 等常见后端通信方式。
了解 Docker、CI/CD、日志监控、告警系统，有自动化部署经验优先。
具备良好的代码规范意识、问题分析能力、责任心和沟通协作能力。
加分项
有腾讯云生产环境实际运维经验，参与过线上系统部署、监控、故障处理和稳定性建设。
熟悉 Kubernetes / TKE、Prometheus、Grafana、ELK / EFK 等监控和日志体系。
有高并发、微服务、分布式系统、消息队列、异步任务等相关开发经验。
有 DevOps、自动化运维平台、发布系统、配置管理系统建设经验。
有安全加固、成本优化、容灾备份、链路追踪、压测调优经验。
有较强的线上问题定位能力，能够独立推动问题闭环和复盘改进。

本岗位偏 云运维后端 / DevOps 后端方向，既需要具备 Go、Python 后端开发能力，也需要能够参与腾讯云环境下的部署运维、监控告警、故障排查和自动化工具建设。适合有后端开发经验，同时对云平台运维和系统稳定性建设有实际经验或浓厚兴趣的候选人。
