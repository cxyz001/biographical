## 职位描述

岗位职责：
1、负责鼎捷 T100 ERP 系统的二次开发与客制化，包含自定义单据、业务逻辑开发、XG/FR 报表开发、审批流程定制，跟进开发、单元测试、UAT 交付全流程。
2、对接生产、供应链、质量、财务业务部门，开展需求调研、可⾏性评估，输出开发⽅案，结合制造业业务痛点推进系统流程优化。
3、负责⿍捷 T100 与 MES、WMS、PLM、OA 等第三方系统之间的接口开发、联调与运维；基于 WebService、RESTful 完成数据同步，处理接口异常问题。
4、负责 Oracle 数据库开发，编写存储过程、视图，进行 SQL 性能优化；处理⽉结、年结过程中的系统数据异常、故障排查。
5、沉淀开发文档、接口手册，梳理内部开发规范；协助内部关键用户培训，支撑业务部门信息化落地。
6、参与信息化项目迭代，识别系统瓶颈，提出技术优化建议，协同推进制造业数字化建设。
 任职要求：
1、本科及以上学历，计算机、软件工程、信息管理与信息系统等相关专业；
2、3‑5 年鼎捷 T100 二次开发经验，熟练 Genero‑4GL 开发语言、Design Studio 开发工具；有实体制造企业甲方开发经验优先（电感 / 电子制造业更佳）；
3、精通 Oracle 数据库，熟练 SQL、存储过程编写与性能调优；熟悉接口开发，了解 WebService、REST 等常用协议；
4、熟悉制造业 ERP 业务流程，理解 BOM、生产工单、进销存、车间报工、成本核算等核心业务逻辑；能够站在业务视角分析需求；
5、具备独立承接复杂开发任务的能力，擅长需求拆解、问题定位排查；良好沟通能力，可直接与业务部门沟通；
6、有 MES‑ERP 集成项目经验优先；具备一定的项目文档撰写能力，工作严谨，责任心强。
