## 职位描述

关于 Kody
Kody 是一家国际化科技公司，在新加坡、伦敦和香港设有办公室。我们专注于构建高质量的软件解决方案，推动技术创新，为全球客户提供可靠的技术产品。
⽬前，我们正在寻找⼀名资深  后端⼯程师，负责构建稳定、高效、可扩展的后端系统。如果你擅长 Kotlin 或 Java，并希望在国际化团队中发挥技术影响力，我们期待你的加⼊！
职位概述
- 作为 Kotlin 后端工程师，你将负责设计、开发和优化后端服务，支持高流量、高性能的应用程序。你需要在微服务架构、数据库优化、API 开发等领域具备深入理解，同时具备良好的英语沟通能力，可以与国际团队协作。
- 此岗位支持灵活办公安排，需常驻深圳地区，可能会根据团队安排或项目进展，不定期前往办公室或香港参与协作。
岗位职责
- 后端开发：使用 Kotlin（或 Java） 设计、开发和优化后端 API 和服务。
- 架构设计：参与系统架构设计，确保代码质量、可扩展性和高性能。
- 数据库管理：优化SQL/NoSQL 数据库，提高数据存取效率。
- API 设计与开发：构建 RESTful 或 gRPC API，与前端和移动端团队无缝对接。
- 微服务与云部署：开发可扩展的微服务架构，使用 Docker、Kubernetes、AWS/GCP 进行云端部署。
- 性能优化：识别并解决系统性能瓶颈，提升应用运行效率。
- 测试与代码质量：编写单元测试、集成测试，确保代码稳定性。
- 跨团队协作：与前端工程师、产品经理、QA 测试团队紧密合作，推动产品落地。
岗位要求
-  3 年以上 Kotlin 或 Java 后端开发经验，熟悉 Spring Boot、Ktor 或类似框架。
- 熟练使用 PostgreSQL、MySQL、MongoDB 或 Redis 进行数据库管理和优化。
- 熟悉 RESTful API、GraphQL 或 gRPC 设计和开发。
- 熟悉 微服务架构、Docker、Kubernetes，具备云端部署经验（AWS、GCP 或 Azure）。
- 熟悉 多线程、异步编程、消息队列（Kafka、RabbitMQ），优化后端性能。
-  英语沟通能力良好，能够流畅地与国际团队交流。
