## 职位描述

岗位职责
1.用户计费体系架构搭建与开发 独立负责平台账号体系全链路开发：用户注册登录、JWT 鉴权、RBAC 多租户权限管理、套餐充值、用量统计、计费对账、⽋费限流模块设计实现，⽀撑企业 / 个⼈双端付费业务。
2.第三方云 AI 服务封装与音频核⼼服务开发 对接讯飞 / 腾讯云 ASR 语音转写、机器翻译 API，完成统一 SDK 客户端封装、签名鉴权、错误码统一适配；开发音频预处理服务，基于 FFmpeg 实现音频转码、分片上传、时长校验、断点续传能力，落地长文件异步转写、实时流式语音识别业务。
3.AI 能力后端全链路开发 搭建统一大模型接入适配层，对接讯飞星火 / 腾讯混元等 LLM，实现会议文本摘要、要点提取、待办事项结构化输出；负责转写文本双语翻译逻辑、字幕 / Word/Excel 文档批量导出服务开发，设计异步任务调度链路（MQ 驱动转写→翻译→AI 总结完整流水线）。
4.全类型接口设计与开发 基于 RESTful 规范设计业务资源接口；开发 WebSocket 实时流式录音转写 / 实时翻译接口；对外提供标准化 Webhook 回调接口（支持第三方系统推送转写、纪要结果），配套前端完成全业务接口交付。
5.中间件与存储落地优化 基于 Redis 实现任务状态缓存、分布式锁、接口 QPS 限流、翻译 / AI 总结结果缓存、实时会话上下文管理；MySQL 完成业务持久化分层设计，保障多租户数据隔离与海量任务查询性能。
6.项目研发协作与迭代 配合测试完成功能自测、性能压测、bug 修复、版本迭代；对接外协研发团队对齐接口规范、排期、问题联调；参与需求评审、输出技术方案、评估开发工作量；输出接口文档、设计文档、部署运维文档等技术资料。
7.代码与工程规范落地 严格执行团队编码规范，持续重构优化老旧代码，优化接口响应速度、异步任务堆积、第三方 API 调用容错、熔断降级等稳定性问题。
任职要求
一、基础硬性要求
1.本科及以上，计算机、软件工程相关专业，3 年及以上 Java 后端开发实战经验；
2.精通 Java 基础，熟练运用 OOP 面向对象思想完成分层、抽象、多态业务设计；

4.熟练使用 MySQL，掌握索引优化、事务、分页、联表查询，具备分场景库表设计能力；
5.熟练使用 Redis，能独立运用 Hash/ZSet/String 等结构实现缓存、分布式锁、限流、临时会话等业务；

7.具备良好编码习惯，重视代码可读性、可复用性，能遵循统一开发规范交付代码。

1.有语音 ASR、机器翻译、大模型 LLM 接入类 AI 后端落地经验优先，做过会议转录、字幕生成、音频处理平台者优先；
2.有 WebSocket 实时流式音频传输、FFmpeg 音频转码处理开发经验；
3.熟悉 RabbitMQ/RocketMQ/Kafka 消息队列，做过长异步任务调度、任务状态机设计；
4.有第三方云平台（讯飞 / 腾讯云 / 阿里云）API 对接、封装、熔断降级实战经验；
5.熟悉 RESTful 接口设计规范，有 Webhook 对外集成接口开发经验；
6.了解微服务 / 分布式基础，懂接口限流、熔断、链路追踪、异常监控；
7.有计费、多租户权限、SaaS 平台后端开发经验；
