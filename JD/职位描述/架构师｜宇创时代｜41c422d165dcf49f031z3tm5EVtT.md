## 职位描述

岗位职责：
1.架构设计与规划： 负责公司核心业务系统的技术架构设计（包括微服务拆分、接口定义、数据模型设计），确保系统的高可用性、高并发性、⾼扩展性和低延迟。
2.技术选型与决策： 根据业务需求，主导技术栈选型、中间件评估及引⼊，制定技术演进路线图（Roadmap）。
3.核⼼代码攻坚： 负责核心模块、公共组件、底层框架的开发与封装，解决开发过程中遇到的复杂技术难题（如内存泄露、死锁、性能瓶颈等）。
4.性能优化与稳定性： 主导系统性能调优（JVM、数据库、中间件），建立系统监控与容灾机制，保障⽣产环境稳定性。
5.团队指导与培养： 指导高级/中级工程师解决技术问题，进行技术分享，提升团队整体技术深度和广度。 
任职要求：
1.语言底层： 精通 Java 语言，深入理解 JVM 原理（内存模型、GC 算法、类加载机制），具备线上 JVM 调优和故障排查（Dump 分析）能力。
2.多线程精通： 极度精通 Java 并发编程（JUC），深入理解内存模型（JMM）、锁机制（AQS, Synchronized, ReentrantLock）、无锁编程（CAS, Atomic）、线程池调优。
3.低延迟编程： 熟悉 Disruptor 等高性能队列，熟悉 Chronicle Map/Queue 等堆外内存 (Off-heap Memory)、内存映射文件 (MappedByteBuffer) 。
4.双栈能力： 精通 Spring Cloud 生态的同时，必须精通 Dubbo RPC 框架，了解其底层通信协议、序列化协议（ProtoBuf, Hessian2, Kryo）及扩展机制，能对 RPC 调用进行极致性能优化。
5.消息中间件： 精通 Kafka 和 RocketMQ，不仅限于使用，需理解其底层设计原理，能处理消息积压、重复消费及保证端到端低延迟。
6.多级缓存架构： 具备设计 L1 (Caffeine 堆内) + L2 (Chronicle Map, 堆外/持久化) + L3 (Redis, 分布式) 多级缓存架构的经验，理解各级缓存的淘汰策略和一致性维护。
7.Redis 进阶： 深入理解 Redis 线程模型、持久化机制、集群分片原理，熟悉 Lua 脚本及 Pipeline 使用。
8.异构数据库：
精通 InfluxDB 或类似时序数据库，适用于监控数据或行情数据存储。
熟练使用 MongoDB，具备海量数据分片（Sharding）及复杂的聚合查询优化经验。
9.关系型数据库： 精通 MySQL/PostgreSQL，深入理解索引数据结构、锁机制、MVCC、事务隔离级别；具备分库分表（Sharding-JDBC/MyCat）、读写分离及 SQL 调优实战经验。
10.Flink 实战： 熟练掌握 Flink 进行实时流计算，理解其 StateBackend、Checkpoint 机制、反压处理（Backpressure）及窗口计算（Windowing），有实时风控或实时数仓项目经验者优先。
11.容器化： 熟练掌握 Docker 和 Kubernetes (K8s)，理解云原生架构（Cloud Native）理念。
12.CI/CD： 熟悉 Jenkins、GitLab CI 等自动化构建部署工具。
13.架构经验：5年以上技术架构设计经验，以技术为主。
综合素质： 
逻辑思维： 具备极强的逻辑分析能力和抽象思维能力，能从复杂的业务中拆解出清晰的技术模型。
沟通能力： 优秀的跨部门沟通协作能力，能将技术语言转化为业务语言与非技术人员沟通。
