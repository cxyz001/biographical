## 职位描述

岗位概述
本岗位面向 AI 影像智能硬件产品，聚焦AI端侧设备 + 前后端服务的全链路研发，是典型的嵌入式全栈定位。你将深度参与产品从原型验证到商用落地的完整周期，以嵌入式 Linux 应⽤开发为核⼼，同时覆盖设备管理后端服务的设计与实现，打通硬件接口、AI 算法落地、云端管控的完整技术链路，保障设备在应⽤场景下低延迟、高稳定运行。
岗位职责
边缘设备端核⼼应用开发
负责嵌入式 Linux 平台的应用层软件开发，对接 MIPI/USB 摄像头采集链路、云台控制模块、YOLO 目标检测推理引擎，实现自动跟拍逻辑、设备状态管控、视频流推流/拉流等核心功能，保障端到端运行低延迟、高可靠。
设备联动后端服务开发
负责设备管理与赛事数据后端的架构设计与编码实现，搭建设备接入鉴权、状态上报、远程参数配置、OTA 差分升级、赛事数据管理等核心服务，实现边缘设备与云端的稳定双向交互。
研发全流程与质量管控
主导软件从需求评审、技术方案设计、编码开发、测试联调到商用版本发布的完整流程，制定并落地代码规范、版本管理、缺陷跟踪与发布归档机制，保障商用交付质量。
跨团队协作与问题攻坚
与算法、硬件、产品团队紧密配合，完成 AI 模型边缘部署、硬件接口联调、业务功能迭代，快速定位并解决现场部署、赛事运行中的各类技术问题。
全链路性能与稳定性优化
持续优化边缘端推理调度效率、视频传输延迟、系统长时间运行稳定性，适配不同硬件平台与户外体育赛事的复杂现场环境。
任职要求
本科及以上学历，计算机、软件工程、电子信息等相关专业，5 年及以上嵌入式 Linux 应用开发经验，有完整商用软件项目从开发到交付的全流程经验。
精通 C/C++ 语言，熟悉嵌入式 Linux 操作系统原理，熟练掌握多线程/多进程编程、内存管理、进程间通信、系统性能调试等核心技能。
熟悉摄像头开发全链路，具备 MIPI/USB 摄像头驱动调试、ISP 调优、RTSP/RTMP 视频流处理的实操经验。
熟悉 UART、SPI、I2C、以太网等常用硬件通讯接口，具备外设驱动联调与问题排查能力。
熟练使用 Git 版本管理工具，具备良好的编码规范、技术文档撰写习惯。
