## 职位描述

岗位重点：完成业务功能，关注一线人员的实际使用体验。 在研发负责人和资深⼯程师指导下⼯作，欢迎有扎实项⽬实践的应届毕业生。
工作职责
1. 业务功能开发： 参与⾤集点、电子签约、结算、设备管理和运营报表等模块，完成页面、接口与数据处理。
2. PC 与移动端体验： 改善 BD 和运营人员的操作流程，处理表单、筛选、分页、文件上传及移动端适配等问题。
3. 联调与质量保障： 根据验收标准完成自测、接口联调和缺陷修复，参与代码审查与发布验证，跟进功能交付后的反馈。
4. 问题排查： 使用日志、SQL 和浏览器工具复现问题，核对页面、接口与数据库结果，清楚记录原因和修复结果。
5. AI 辅助交付： 使用 AI 辅助理解代码、拆解任务、编码和编写测试，实际运行并检查结果，对提交的代码负责。
任职要求
1. 本科及以上学历，计算机、软件工程等相关专业优先。
2. 掌握 Java、SQL 和 Spring Boot 基础，能够完成简单业务接口和数据库操作。
3. 掌握 JavaScript、HTML/CSS，理解 HTTP、前后端交互和基本移动端适配；愿意在现有原生 JavaScript 项目中开发与维护。
4. 熟悉 Git，有项目或实习实践，能讲清自己完成的部分、遇到的问题和解决过程，沟通及时。
5. 使用过 AI 辅助开发，能描述需求、补充上下文、检查代码，并通过实际运行验证结果。
加分项
- 用 AI 完成过从需求、开发到部署的完整项目，能展示自己的判断、修正及验证过程。
- 有被真实用户使用的 Web、H5 或小程序项目，并根据反馈持续改进的经历。
