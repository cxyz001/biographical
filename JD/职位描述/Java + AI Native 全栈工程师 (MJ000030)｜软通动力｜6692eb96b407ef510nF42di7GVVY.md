## 职位描述

我们寻找的不是“偶尔使用 AI 的 Java 工程师”，而是能以 Java 为核心技术底座，深度结合 AI Coding ⼯具，⾼效完成复杂业务交付的 AI Native 全栈⼯程师。
岗位职责：
1. 参与业务需求分析、系统设计、技术方案制定及核心模块开发，独⽴推动研发任务高质量交付；
2. 以 Java 后端能力为基础，深度使用 Qoder、Claude Code、Codex 等 AI Coding 工具，高效完成后端、前端甚至移动端及其他技术栈相关开发任务；
3. 负责线上系统稳定性，参与故障定位、问题排查、性能优化、成本优化及可靠性建设；
4. 面对模糊需求和不确定场景，能够主动发现问题、定义问题、提出方案并推动落地。
---
任职要求：
1. 本科及以上学历，计算机、软件工程等相关专业优先；2 年及以上 Java 开发经验，具备扎实的计算机基础；
2. 熟悉 Java EE 技术体系，熟练使用 Spring、Spring MVC、MyBatis、Spring Boot、Spring Cloud 等主流框架；
3. 熟悉 MySQL 及常见关系型数据库，具备数据库建模、SQL 编写与性能优化能力；了解缓存、消息队列、NoSQL 等常见中间件；
4. 熟悉 Linux 操作系统及 HTTP/HTTPS/TCP 等常见网络协议，理解 Java IO、多线程、集合框架等底层机制；
5. 真正将 AI Coding 融入日常研发流程，熟练使用至少一种主流工具，如 Qoder、Claude Code、Codex 等，有 AI coding 工程化落地经验者优先；
6. 对代码质量和线上结果负责，具备强自驱力、责任感和结果导向意识，能在需求模糊、节奏快速变化的环境中独立推进任务；
7. 具备良好的沟通协作能力，习惯使用工程规范、自动化工具和 AI 工具提升团队研发效率；
8. 有 LLM 应用、Agent、RAG、AI 工作流、智能客服、知识库等 AI 应用开发经验者优先。
