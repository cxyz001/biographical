## 职位描述

岗位介绍
我们正在寻找一位具备扎实固件开发能力的高级固件工程师，加⼊ AIVELA 智能可穿戴产品团队。
这个岗位不要求你⼀开始就独⽴负责所有底层架构设计，也不要求你必须是固件领域的顶级专家。我们更希望你具备扎实的工程基础、较强的问题分析能力和⾮常强的学习能力，能够快速理解产品、代码和供应商交付内容，并在实际项目中不断成长。你需要能够看懂固件代码，发现明显问题，参与调试和修复；也需要和外部固件供应商保持高效沟通，跟进问题闭环，协助团队提高固件交付质量和产品稳定性；适配创业团队模式，个人战斗力强、独立性强、执行力强，能承担多维度技术工作。

岗位职责
固件研发与调试
- 参与智能可穿戴产品固件模块的开发、调试、优化和问题修复。
- 配合资深固件负责人，完成 BLE、传感器、低功耗、OTA、Flash 存储等相关模块的开发和验证。
- 对供应商交付的固件问题进行复现、定位、分析，并参与推动修复。
供应商协同与问题跟进
- 协助公司与固件外包供应商进行日常技术沟通、需求确认和问题跟进。
- 跟踪供应商开发进度和 bug 修复状态，确保问题有明确结论和闭环。
- 对供应商交付内容进行基础技术判断，识别明显的实现问题、逻辑缺陷或交付风险。
代码审核与质量把关
- 参与供应商固件代码的 Code Review，协助发现代码逻辑、稳定性、可维护性方面的问题。
- 根据团队要求，对关键模块进行测试验证，包括连接稳定性、功耗表现、数据采样、OTA 升级等。
- 将项目中反复出现的问题整理为 checklist、问题记录和技术文档，帮助团队提升后续评审效率。
测试验证与问题闭环
- 从固件底层角度参与产品测试，发现普通功能测试不容易覆盖的问题。
- 协助分析量产、用户反馈、App 联调过程中出现的固件相关问题。
- 跟进问题从发现、定位、修复到验证的完整闭环，避免问题只停留在表面修复。

- 有较强的学习能力，能够快速理解新平台、新模块和新问题。
- 做事细致、负责，能够持续跟进问题，不轻易放过模糊结论。
- 沟通清晰，能够与供应商、App、算法、硬件、测试等团队协同推进问题。
