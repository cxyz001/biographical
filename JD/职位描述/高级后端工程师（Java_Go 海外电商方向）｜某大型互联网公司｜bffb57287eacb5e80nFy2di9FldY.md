## 职位描述

PETO是一家总部位于美国硅谷、日本东京的全球化高端宠物电⼦科技品牌。团队由奥美全球主创、苹果、⾕歌、IDEO等国际顶尖机构的设计师、艺术家、可持续发展专家与宠物⾏业专家联合创立。品牌聚焦高端智能宠物电⼦产品，以前沿设计、科技创新、可持续理念为核心，重构全球宠物电子视觉与产品标准。目前已在宁波、杭州、深圳设立分支机构，面向全球市场打造兼具未来感与温度的宠物科技产品。
一、岗位职责：
1. 负责海外独立站订单、支付、库存、促销、退款、物流等核心系统的设计、开发和维护。
2. 负责高并发、高可用系统建设，持续优化接口性能、数据库性能和系统稳定性。
3. 负责对接海外支付、物流、ERP、仓储及其他第三方平台。
4. 参与线上部署、监控告警、容量规划、故障排查、应急处理和服务恢复。
5. 处理支付回调异常、重复下单、库存超卖、消息积压、数据库故障等突发问题。
6. 完善限流、熔断、降级、重试、幂等、数据一致性及灾备机制。
7. 参与技术方案评审、代码审查和系统架构持续改进。
8. 配合前端、测试和运营团队，保障大促及业务高峰期稳定运行。
二、任职要求：
1. 计算机相关专业，5年以上后端开发经验，有大型电商、交易、支付或高并发系统经验。
2. 精通 Java 或 Go，至少深入掌握其中一种：
   - Java方向：熟悉 Spring Boot、Spring Cloud及常用中间件。
   - Go方向：熟悉 Gin、GoFrame等框架，理解并发模型和性能优化。
3. 熟练使用 MySQL或PostgreSQL，具备SQL优化、索引设计、事务、锁及故障排查能力。
4. 熟悉 Redis，以及 Kafka、RocketMQ、RabbitMQ等至少一种消息队列。
5. 熟悉分布式系统，掌握幂等、分布式锁、缓存一致性、最终一致性、限流、熔断和服务降级。
6. 熟悉 Linux、Shell、Git、Nginx、Docker及CI/CD流程。
7. 具备生产环境故障处理经验，能够快速定位问题、止损、回滚并恢复服务。
8. 熟悉 AWS或其他海外云平台，了解Cloudflare、CDN、DNS、HTTPS及基础安全防护。
9. 具备良好的责任心、沟通能力和问题分析能力，能够参与必要的线上应急响应。
三、优先条件：
1. 有海外独立站、跨境电商或大型商城项目经验。
2. 有信用卡、PayPal、Stripe等海外支付系统对接经验。
3. 处理过高并发下单、库存超卖、重复支付、消息积压或数据库性能事故。
4. 熟悉 Kubernetes、Prometheus、Grafana、ELK或Loki。
5. 有压测、容量评估、自动扩容、异地备份及容灾演练经验。
6. 具备一定英文技术文档阅读和海外第三方平台沟通能力。
四、核心技术栈：
Java / Go、MySQL / PostgreSQL、Redis、Kafka / RocketMQ / RabbitMQ、Linux、Docker、Kubernetes、AWS、Cloudflare、Prometheus、Grafana。
五、岗位说明：
本岗位以后端研发为主，同时要求具备线上运维和应急处理能力。候选人需要参与线上值班或紧急故障响应，具体值班制度、补贴及调休安排将在入职前明确。
六、面试重点：
准备介绍一个亲自处理过的生产事故，包括事故现象、排查过程、临时止损措施、根本原因和后续改进方案。
