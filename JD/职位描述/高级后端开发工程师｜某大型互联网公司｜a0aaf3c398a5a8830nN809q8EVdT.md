## 职位描述

岗位职责：
1.负责 AI Agent 平台核心后端架构设计与开发，包括 Agent 编排引擎、任务调度、工具调用（Tool Calling）、记忆管理、多轮对话状态管理等核心模块。
2.设计并实现 ⾼并发、低延迟的 Agent 运⾏时服务，⽀撑大规模并发会话与长链路任务执行。
3.负责 LLM 接⼊层建设，统一对接 OpenAI、Anthropic、国产大模型等多provider，实现流式响应、重试降级、成本与限流控制。
4.构建 Agent 可观测性体系：链路追踪、Token 计量、执行日志、效果评估与回放。
5.参与 云原生基础设施建设，推动服务容器化、K8s 部署、CI/CD 与自动化运维落地。
6.与算法、产品团队紧密协作，将 Agent 能力快速工程化、产品化。
7.参与技术选型、代码评审、技术难点攻关，并指导中初级工程师成长。
任职要求：
1.本科及以上学历，计算机相关专业，3 年以上后端开发经验。
2.精通 Go：熟悉 Goroutine、Channel、GC 机制、性能调优，有高并发服务实战经验。
3.精通 TypeScript：熟悉 Node.js 生态，能独立开发/维护 TS 后端服务（NestJS / Express / Fastify 等）。
4.熟悉 分布式系统设计：微服务、消息队列（Kafka/RabbitMQ/NATS）、缓存（Redis）、数据库（PostgreSQL/MySQL）。
5.熟悉 API 设计：RESTful / gRPC / WebSocket，具备良好的接口抽象与版本管理能力。
6.有 LLM / AI Agent 相关工程经验：熟悉 Function Calling、RAG、Prompt 工程、Agent 框架（LangChain / LlamaIndex / 自研）之一。
7.具备良好的工程素养：单元测试、代码规范、Git 协作、技术文档能力。
