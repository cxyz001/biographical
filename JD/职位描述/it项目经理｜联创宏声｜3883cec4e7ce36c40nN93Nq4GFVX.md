## 职位描述

【关于我们】
星转美好科技是国内奢侈品循环服务企业，专注于高端闲置物品的鉴定、回收与流通，我们拥有庞大的股东背景和专业的服务团队，现因业务发展需要，诚邀一名既懂技术又对业务有好奇⼼的IT开发⼯程师加⼊，与我们一起用代码守护“美好”。
【岗位职责】 
1.系统开发与维护：负责公司内部业务系统（包括但不限于商品管理系统、鉴定中台、订单履约系统、CRM等）的设计、开发与迭代；
2.需求分析与落地：理解奢侈品鉴定、回收、销售等业务场景，与运营、鉴定等部门紧密配合，将复杂的业务需求转化为⾼效的技术解决方案；
3.接口对接与优化：负责与第三方平台（电商平台、支付机构）的API对接，确保数据流稳定通畅；
4.性能优化与重构：持续优化现有系统的性能、可扩展性及用户体验，解决系统运行过程中的技术难题；
【任职要求】 
1.本科及以上学历，计算机科学与技术、软件工程等相关专业毕业；
2.具备2年以上的IT项目经理经验，有过电商行业项目开发/产品经验优先；
3.熟练掌握至少一种主流后端开发语言（如 Java / Python / Go / PHP）；
4.对数据敏感，逻辑思维能力强；具备良好的沟通能力和团队协作精神；
