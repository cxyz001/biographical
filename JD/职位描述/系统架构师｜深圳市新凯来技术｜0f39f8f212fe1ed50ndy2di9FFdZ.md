## 职位描述

岗位职责：
1、主导智能座舱域控制器虚拟化基座（Hypervisor）整体技术方案设计、核心模块开发、全流程调试及性能优化，保障虚拟化平台的高可用性与可扩展性；​
2、负责虚拟化环境下 I/O 设备（⽹络、存储、外设、GPU 等）的驱动架构设计、适配开发与调度机制优化，提升设备访问效率与稳定性；​
3、主导 Android 系统内核与 Framework 层的虚拟化适配，完成 Linux 域与 Android 域的跨域通信协议设计、资源共享机制优化，确保多域协同稳定运⾏；​
4、结合智能座舱客户实际业务需求，迭代优化虚拟化平台的性能表现（如启动速度、响应延迟）、资源隔离能⼒、功能安全（ISO 26262）及信息安全合规性，支撑产品规模化落地；​
5、参与嵌入式系统底层软件架构设计，负责核⼼模块拆分、接口定义与技术选型，保障系统具备高性能、高可靠性与可维护性；​
6、主导跨系统（Linux-Android）场景下的技术难题定位与全链路优化，解决虚拟化层、内核层、应用层的兼容性与性能瓶颈问题；​
7、编写并维护架构设计文档、技术方案手册、核心模块设计流程图，输出标准化技术交付物，支撑团队研发协作与知识沉淀。
任职要求：
1、本科及以上学历，计算机科学与技术、软件工程、电子信息工程等相关专业，5 年以上 Linux 内核或 BSP 开发经验，具备 Hypervisor / 虚拟化领域深度开发经验；​
2、精通 C/C++ 编程（核心要求），熟悉 JAVA 或 Rust 开发，严格遵循行业编程规范，具备高质量、高可读性的代码编写能力；​
3、深入理解操作系统核心原理，精通 Linux 系统（Ubuntu/Yocto/OpenWRT 等）内核架构，熟练掌握进程调度、内存管理、中断机制、I/O 虚拟化等核心技术；​
4、精通主流虚拟化技术体系，深入掌握 1-2 种核心方案（Xen/KVM/QEMU/Container），能独立完成虚拟化组件的代码级开发与定制化修改；​
5、熟悉 Hypervisor 层关键技术（如 CPU 虚拟化、内存虚拟化、设备虚拟化），深入理解 QEMU、KVM、Libvirt 等组件的工作机制与集成方案；​
6、具备 virtIO 驱动架构设计、性能调优经验者优先；拥有 GPU 虚拟化（如 vGPU）、智能座舱域控制器虚拟化项目经验者尤佳；​
7、具备扎实的架构设计能力与技术选型判断力，逻辑思维清晰，能快速定位并解决复杂系统的底层技术难题；​
8、良好的跨部门沟通协作能力，能主导技术方案评审与跨团队协作，具备带领小团队推进核心项目的经验者加分；​
9、良好的英语读写能力，能熟练阅读虚拟化技术手册、内核源码文档及行业标准规范，听说能力优异者优先。
