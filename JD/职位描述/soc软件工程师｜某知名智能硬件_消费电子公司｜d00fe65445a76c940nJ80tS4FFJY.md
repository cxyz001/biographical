关于我们
我们是行业领跑的 AI 智能照明光机赛道的科技创业公司，手握量产级全栈光机技术底座与行业领先的物理 光学AI生成式引擎双壁垒，站在智能照明从「参数化设定」迈向「场景化AI 原生生成」的行业拐点，面向智能汽车、无人机、安防、医疗等领域的高性能照明需求，提供从光学算法到硬件执行的全链路一体化产品方案。
公司已完成天使轮融资，业务由行业领军人物带领，我们将率先推进行业AI高性能照明在汽车市场的量产落地，技术、专利卡位与业务节奏均处于行业第一梯队，成长空间与长期价值充足。
我们不做悬浮的概念 AI，也不做内卷的传统方案：底层以经过量产验证的车规microLED光机体系为根基，上层以独创的物理光学 AI生成式引擎为核心竞争力。我们将光学定律、车规法规、芯片物理特性深度嵌入模型和算法约束，生成满足用户照明痛点需要、物理可落地、符合法规合规要求的全新一代照明产品，彻底突破传统方案的场景天花板。
我们正在寻找 软件开发负责人：既能亲自动手把 SOC 控制器软件系统从 0 到 1 跑通，也愿意成为软件负责人，带出一个小而强的嵌入式软件团队，共同定义并落地产品软件体系。

岗位职责
作为软件负责人，你将主导 SOC 控制器软件平台从 0 到 1 的全链路搭建与落地，亲自开发，并组建并带领团队。
技术边界说明：核心工作聚焦 ARM Cortex-A 侧嵌入式 Linux 平台搭建与业务开发，协同负责异构核（Cortex-M）固件联调；负责多源数据接入、数据流调度、实时控制与业务逻辑实现。姿态解算、地图融合、AI 光型生成等核心算法由算法团队输出，你负责集成、部署与性能优化，不必精通所有算法细节。
1. 软件平台架构设计
负责 SOC 控制器软件平台整体架构设计，定义 BSP、系统服务、中间件、应用层之间的模块边界与接口，沉淀可复用的驱动框架、硬件抽象层（HAL）封装、标准化 SDK 接口，为后续多个控制器项目提供统一软件基座。
2. 车规软件质量体系建设
牵头搭建车规级软件质量与功能安全体系框架，按照 ISO 26262 功能安全要求与 ASPICE 开发流程，建立软件需求追溯、变更管理、配置管理等机制，支撑产品从原型验证到车规级量产的跨越。初期以体系框架搭建与流程落地为主，后续配合第三方机构完成 ASIL-B 等级（或项目目标等级）功能安全认证。
3. 系统与 BSP 开发
基于 ARM 架构芯片官方 SDK，完成嵌入式 Linux 开发环境搭建、U-Boot 移植、内核裁剪适配、根文件系统构建与启动速度优化。
4. 外设驱动开发
负责外设驱动开发、适配与调试，覆盖 MIPI 数据输入接口、以太网、USB、SPI、I2C、UART、CAN/FD、GPS/定位模块接口、IMU 传感器接口、显示/触控接口、多通道高精度 PWM（阵列式光源驱动）、GPIO 等常用接口，解决底层驱动的稳定性与兼容性问题。
5. 核心数据通路打通
 完成姿态传感器数据（IMU）、地图/定位数据、人机交互指令、图像数据等多源输入接入，经过数据融合、光型数据预处理、帧同步调度，最终驱动照明阵列高精度 PWM 输出，搭建“感知-决策-执行”的基础数据通路。
6. 业务功能开发
 实现控制器核心业务逻辑，包括但不限于：人机交互逻辑（触摸/姿态等输入解析与响应）、姿态数据处理与融合（集成算法团队提供的姿态解算模块）、地图/定位数据接入与场景化光型决策、投影光型控制（图像矫正、融合、画面管理）、状态管理、故障诊断、外设执行器控制等。保障功能的实时性与可靠性；对接光学算法与 AI 光型引擎团队，完成算法模型在 SOC 平台的部署、适配与性能优化，保障光型输出的实时性与准确性。
7. 系统调优与联调
配合硬件工程师完成单板 Bring Up 与软硬件联调，针对启动时延、内存占用、系统稳定性、中断实时性进行持续调优，确保关键指标满足车规与业务实时性要求。
8. 工程体系搭建
建立代码版本管理、自动化构建、版本发布、开发文档规范、问题跟踪等研发流程；引入代码审查、静态扫描、单元测试等质量管控机制，为后续团队扩张和车规认证打下工程化基础。
9. 团队与业务管理
参与产品需求评审与技术方案选型，对接芯片厂商、硬件团队、产品/业务方；制定软件技术路线图，把控技术风险与交付节奏；后续负责招聘和培养嵌入式软件工程师，进行任务拆解、代码审核、技术决策，对软件交付进度与质量负责。
