## 职位描述

职位描述
1. 负责公司全量代码资产的统一管理，包括 Git / GitLab / Gerrit / Repo 的搭建、配置、权限管控、
备份及安全审计；制定并优化分支策略，保障代码合并质量。
2. 负责 Android / Debian / OpenHarmony 多智能操作系统平台的 CI/CD 流水线设计与落地；基于
Jenkins / Quickbuild 构建覆盖多款 SOC（瑞芯微、高通、MTK 等）的自动化编译、打包、签名与
发布流程，并持续优化编译资源负载均衡。
3. 负责开发、测试、预发及生产环境的部署交付与变更支持；维护 CI/CD 服务器及 Redis、MySQL、
Nginx、Kafka / RabbitMQ 等中间件。
4. 利用 Shell / Python 脚本及 AI 工具实现部署、巡检、排障自动化；参与监控、告警、日志运维体系
的日常维护。
5. 维护运维文档与知识库，为研发团队提供配置管理工具及流程的培训与技术支持。
任职要求
1. 本科及以上学历，计算机、电子、自动化等相关专业。
2. 扎实的 Linux 运维能力，能独立完成服务管理、日志分析、基础发布及故障排查。
3. 熟悉 Git / GitLab / Gerrit / Repo 等源码管理工具的使用、配置、升级及备份。
4. 熟悉 Jenkins / Quickbuild 等 CI/CD 平台，具备软件构建与发布的工程实践经验。
5. 熟练使用 Shell / Python 进行日常运维与自动化脚本开发。
6. 熟悉 Docker 容器化技术及常用命令；了解 TCP/IP、路由、防火墙、VLAN 等基础网络知识。
7. 熟悉 Redis、MySQL、Nginx、Kafka / RabbitMQ、LVS、Keepalived 中至少 2 种技术。
8. 具备堡垒机环境下的代码安全管理经验。
加分项
1. 具备多款 SOC（瑞芯微 RK、高通、MTK 等）项目编译打包经验。
2. 具备 Kubernetes、KVM 等容器或虚拟化运维经验。
3. 具备监控告警平台（Prometheus、Grafana、ELK 等）维护经验。
4. 熟悉 Sonar、Coverity 等静态代码检查工具。
5. 有 AI 工具辅助运维、部署、排障或自动化交付的实践经验。
6. 有车载、工控或嵌入式行业背景。
