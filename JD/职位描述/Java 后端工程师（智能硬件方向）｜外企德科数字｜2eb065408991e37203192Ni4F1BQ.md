## 职位描述

【岗位定位】
负责公司智能硬件产品的云端后台系统开发，包括设备连
接、数据上云、AI 服务调用、用户管理、应用服务等后台能
力建设，⽀撑我们下⼀代 AI + 智能硬件产品的功能落地。
【岗位职责】
1. 智能硬件后台服务开发（核⼼）
- 负责智能设备的后台服务设计与开发，包括设备注册、鉴
权、心跳、远程控制、数据上报、日志管理等核⼼模块。
- 负责设备 OTA（固件升级）、参数下发等设备生命周期管
理系统的开发。
- 参与设备接入协议的定义，包括 MQTT/HTTP/WebSocket/
TCP 等方式。
- 研发高并发、高可用的 IoT 设备管理平台，确保大量设备稳
定在线运行。
2. AI 能力接入与应用开发（重点）
- 接入第三方或自研的 AI 服务（如语音识别、TTS、翻译、
推荐算法、大模型 API 等）。
- 开发“AI + 智能硬件”相关业务逻辑，如 AI 语音助手、AI 翻
译服务、AI 行为分析、智能调参等。
- 将 AI 推理服务与硬件数据打通，构建端云协同 AI 能力。
3. 后台业务系统 & API 开发
- 开发面向 App、运营后台、合作伙伴的 RESTful API / 
WebSocket 服务。
- 设计用户体系、设备绑定体系、账号鉴权（Token/OAuth2）
等基础能力。
- 与移动端和嵌入式团队联调，确保接口稳定、安全、高效。
4. 数据平台建设与运营支撑
- 搭建设备数据采集、清洗、存储、分析的后端链路。
- 实现设备监控、行为分析、错误日志聚合、告警系统等。
- 支持 AI 模型训练数据提取、产品数据看板输出等需求。
5. 系统架构设计与性能优化
- 参与后台系统架构设计，确保可扩展性和高可用性。
- 使用并优化分布式服务、缓存/消息队列（Redis/Kafka/
RabbitMQ）。
- 提升系统性能、安全性和维护性。
【岗位要求】
技术要求：
- 熟练掌握 Java，精通 Spring Boot / Spring Cloud。
- 熟悉 MySQL、Redis、MQ（Kafka/RMQ）、Elasticsearch 等。
- 有分布式/高并发系统经验优先。
- 有 IoT 设备后台开发、MQTT/WebSocket 经验优先。
- 有 AI API 调用经验（ASR/TTS/翻译、大模型）者优先。
- 熟悉阿里云/火山引擎/AWS 云服务优先。
经验要求：
- 3 年及以上 Java 开发经验（优秀者可放宽）。
- 有智能硬件、IoT、可穿戴设备后台经验优先。
- 有从 0 到 1 系统搭建经验加分。
软技能要求：
- 文档能力、沟通能力、系统性思维。
- 能与硬件、嵌入式、App、产品团队紧密协作。
- 对 AI + 智能硬件技术有热情。
加分项：
- 熟悉 BLE/WiFi/配网流程
- 熟悉 OTA 升级机制
