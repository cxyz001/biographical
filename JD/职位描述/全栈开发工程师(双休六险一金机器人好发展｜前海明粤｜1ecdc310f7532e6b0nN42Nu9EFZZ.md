## 职位描述

岗位职责
1. 全栈核心研发： 负责“天工”平台与客户端产品的前后端功能开发，覆盖 RESTful API 设计、微服务接口实现、前端页面与交互组件开发，并编写必要的单元测试与集成测试、自动化测试；
2. 系统架构落地： 参与⼯业移动机器⼈系统平台软件（myRCS 调度平台、myFMS 柔性排程平台）的架构设计与迭代优化，确保系统的⾼可用性、横向扩展能力与版本兼容性；
3. 关键模块研发： 负责多机交通管制、任务调度策略、SCADA 数据⾤集与监控、3D 数字孪生可视化等模块的需求拆解、技术方案设计与研发推进；
4. AI 驱动研发实践： 在个人日常开发中深入使用 AI 辅助编码工具，形成并持续迭代个人 AI 工作流；主动探索并将有效的 AI 实践沉淀为团队可复用的规范、提示词模板或自动化脚本，提升团队整体研发效能；
5. 工程效能建设： 持续优化团队研发流程，推进自动化测试、CI/CD 流水线、代码质量门禁与容器化部署实践，提升持续交付能力；
6. 技术预研与分享： 跟踪 IoT、工业软件、前端图形学、规则引擎及 AI 编程等领域的前沿技术，定期进行团队内部技术分享，推动新技术在具体业务场景落地；
7. 跨团队协作： 与算法工程师、前端工程师、测试工程师及交付团队紧密配合，保障软件从研发到现场交付的高效协同。
岗位要求
1. 行业不限，计算机科学、软件工程、自动化、数学等相关专业，本科及以上学历；
2. 具有扎实的计算机基础，熟悉 Linux 开发环境，具备良好的数据结构、算法与网络基础；
3. 真正的全栈开发经验，至少5年：
    ○ 拥有从需求到上线的端到端交付能力，前后端均有独立负责完整模块的实战经验；
    ○ 允许有个人技术侧重（或后端或前端），但必须具备快速补齐短板并主导跨层开发的能力；
    ○ 后端： 至少精通一种主流后端语言（Java/Kotlin、Golang、TypeScript(Node.js)、Rust 中任意一种或多种），并有对应的微服务/网络服务框架实际项目经验；具备多语言技术栈的切换和融合开发能力，不局限于单一语言体系；
    ○ 前端： 至少2年 React 或 Vue 工程化开发经验，熟练使用 TypeScript，理解前端性能优化与浏览器渲染原理；
4. AI-Native 开发经验：
    ○ 有代码品味和产品品味，高要求
    ○ 深度使用过至少一种 AI 辅助编码工具（如 GitHub Copilot、Cursor、通义灵码等），并有意识地构建和优化个人 AI 工作流；
    ○ 能够清晰阐述 AI 在需求理解、架构设计、编码实现、测试生成、Code Review 等环节中的实际应用与效果；
5. Solo 与 AI Builder 经验：
    ○ 有独立完成项目/产品的经验（Solo），或利用 AI 工具从零构建完整应用（AI Builder）的经验；
    ○ 能提供可演示的作品、代码仓库或项目文档；
6. 活跃的开源参与痕迹：
    ○ 拥有至少一项可验证的开源参与记录：个人开源项目、第三方项目贡献（PR / Issue / 讨论）、持续维护的技术博客或笔记仓库等；
    ○ 具备良好的英文技术文档阅读能力，能快速理解英文原厂文档与 SDK 说明；
7. 熟悉事件驱动架构、响应式编程模型，有分布式系统开发经验；
8. 对 OOP 有较深理解，熟悉 DDD 领域驱动设计思想，理解微服务架构的拆分原则与治理方案；
9. 熟悉至少一种消息中间件（RabbitMQ / Kafka / RocketMQ）；熟悉至少一种时序数据库或图数据库（如 InfluxDB、IoTDB、Neo4j 等），并对 MongoDB 等主流 NoSQL 数据库有实际项目使用经验，理解其适用场景与数据建模方式；
10. 工作积极主动、认真负责，具备较强的抗压能力与团队协作精神，能适应交付型项目短期出差（单次出差时长不超过1个月）；
11. 逻辑思维清晰，具有良好的抽象能力与沟通表达能力，具备持续学习和自主钻研的意愿。
