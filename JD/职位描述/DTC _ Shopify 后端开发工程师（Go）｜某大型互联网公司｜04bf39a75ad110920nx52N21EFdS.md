## 职位描述

岗位职责：
1. DTC 平台后端架构与功能开发
负责 DTC 独立站后端服务的架构设计、核心功能开发与持续迭代。
基于 Shopify Admin API、Storefront API、REST API、GraphQL API 及 Webhook，开发商品、SKU、订单、客户、库存、支付、物流和售后等核心业务功能。
负责 Shopify 与公司内部业务系统之间的数据交互，保证业务数据正常流转。
编写并维护相关技术⽂档，保障系统的可维护性和可扩展性。
2. Shopify 应⽤与扩展开发
负责 Shopify Custom App、Public App 及相关后端服务的设计与开发。
⽀持 Shopify 主题扩展、Checkout Extensibility 及结账页扩展，为前端扩展提供稳定的接口和数据服务。
针对标准能力无法覆盖的业务场景，开发商品管理、订单处理、营销活动、会员及售后等定制化功能。
跟进 Shopify API 版本及⽣态变化，完成接口适配、系统升级和兼容性维护。
3. 第三方系统集成与数据同步
负责 Shopify 与 物流及营销、客服等第三方系统的集成。
实现订单、商品、库存、客户、支付、退款及物流信息的自动同步和双向联动。
设计跨系统数据同步方案，处理接口鉴权、数据转换、状态映射、异常补偿及数据对账。
建设同步任务、定时任务和异步处理机制，完善失败重试、人工补偿及数据校验流程。
4. Webhook 与事件驱动业务
负责 Shopify Webhook 的配置、接收、验签、消费及异常处理。
覆盖订单、支付、发货、退款、客户、商品和库存等核心业务事件。
基于事件驱动方式实现订单、库存、物流及售后的自动化流转。
设计幂等处理、重复消费防护、延迟处理、失败重试和死信补偿机制。
及时排查数据延迟、数据丢失、重复处理、接口异常及业务状态不一致等问题。
5. 业务需求落地
与运营、产品、市场、供应链及客服团队协作，分析并拆解业务需求。
围绕营销活动、会员体系、订单履约、售后服务及转化优化等场景，输出技术方案并推动落地。
负责需求评估、技术设计、开发、自测、联调、上线及线上维护的完整流程。
6. 系统稳定性与安全建设
负责后端服务的性能优化、并发处理及稳定性建设，支持大促和批量订单等高负载场景。
优化接口响应、数据库查询、异步任务及批处理效率，解决接口超时、任务堆积和库存不一致等问题。
负责接口鉴权、权限控制、参数校验、Webhook 验签及敏感数据保护。
建设日志、监控、告警和链路追踪体系，提升线上问题的发现、定位和处理效率。
持续优化系统架构、代码质量、业务流程和研发效率。
7. 数据服务与报表支持
负责订单、商品、客户、库存、支付、退款、物流和营销等业务数据的统计、查询与输出。
为运营分析、商品管理和业务决策提供稳定、准确的数据服务。
任职要求：
本科及以上学历，计算机、软件工程或相关专业。
3 年及以上后端开发经验，有 Shopify 独立站或跨境电商项目经验。

熟悉 Redis、消息队列、定时任务及异步任务处理机制，理解幂等、重试、限流、熔断和数据一致性设计。
熟悉跨境电商核心业务流程，包括商品、订单、库存、支付、退款、物流、客户及售后。
