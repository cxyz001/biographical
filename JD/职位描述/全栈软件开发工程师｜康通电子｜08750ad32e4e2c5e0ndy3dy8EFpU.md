## 职位描述

岗位职责
1.参与公司核心产品的需求分析、架构设计与技术方案制定，负责前后端核心模块的开发、迭代与优化；
2.负责后端服务接口设计、业务逻辑实现、性能调优及高可⽤保障，保障服务稳定⾼效运⾏；
3.负责前端页面开发、交互实现与工程化构建，配合 UI/UX 完成⾼质量前端交付；
4.负责数据库表结构设计、SQL 优化、索引规划及数据存储方案设计，保障数据安全与查询效率；
5.合理运用 AI 大模型工具赋能研发流程，提升编码效率、代码质量与问题排查速度；
6.参与代码评审、技术沉淀与团队协作规范建设，推动研发流程标准化与高效化。
任职要求
1.学历与基础：计算机科学、软件工程或相关专业统招本科及以上学历，具备扎实的计算机理论基础，熟练掌握数据结构、算法、计算机网络、操作系统等核心知识；
2.后端技术
优先条件：熟练使用 Go 语言进行服务端开发，深入理解 Go 并发模型、内存管理机制，具备 Go 项目性能调优实战经验；
可接受条件：具备扎实的 C++ 或 Java 研发功底，基础牢固，愿意并可快速切入 Go 语言生态开展工作；
3.前端技术
优先条件：熟练掌握 React 框架与 TypeScript，熟悉现代前端工程化、模块化开发，掌握主流状态管理方案；
可接受条件：精通 Vue+JavaScript 技术体系，具备良好前端开发习惯，愿意在工作中快速学习并落地 React+TS 技术栈；
4.数据库与存储：熟练掌握 MySQL 数据库设计与开发，理解索引原理、事务机制及慢查询优化方法，熟悉 PostgreSQL、Oracle 等关系型数据库者优先；熟练使用 GORM 等常见 ORM 框架；
5.AI 工具应用：具备将 AI 大模型工具融入日常研发工作流的实际经验，可独立借助 AI 工具完成代码编写、缺陷排查、逻辑优化等工作，显著提升开发效率与代码质量；
6.综合素养：具备良好的问题分析与解决能力，责任心强，具备良好的团队协作意识与沟通能力，能快速适应业务需求变化。
