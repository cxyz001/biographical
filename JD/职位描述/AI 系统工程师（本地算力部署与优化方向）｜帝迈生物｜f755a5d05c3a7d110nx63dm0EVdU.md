## 职位描述

【公司简介】
专注 AI 算力设备和服务的高科技初创公司，为千行百业客户提供优质算力与 AI 应⽤解决⽅案。
公司处于初创阶段，您将是产品研发核⼼成员，直接向总经理汇报，负责给客户交付产品的技术性能。
【岗位职责】
一、硬件定义与整机验证（约 30%）：
1. 基于某个产品规格（示例：70B 模型、400 tokens/s、TTFT ≤1s、显存 ≥192GB、TDP ≤600W、噪⾳ ≤50dB），向机箱、主板、电源、散热、GPU 等各品类供应商提出明确的硬件选型与规格需求，审核供应商方案的兼容性与合理性；
2. 搭建整机压力测试体系并执行验收：GPU 满载/显存带宽实测、7×24 小时稳定性、功耗、温升、噪音测试，验证各硬件性能达标，输出测试报告并推动供应商整改；
3. 建立整机交付前的标准化验收流程与预装系统镜像，确保"开箱即用"。
二、本地模型部署与性能优化（核心，约 50%）：
1. 负责本地大模型的选型、部署与调优：完成模型量化（AWQ/GPTQ/FP8 等）、推理引擎（vLLM / TensorRT-LLM / SGLang / llama.cpp）选型与参数级调优（上下文长度、KV Cache、批处理与并发调度、采样参数），使整机实际输出达到规格承诺的 Token 速度与 TTFT 指标；
2. 负责知识库与 Agent 工具链的部署：RAG（Embedding、向量库、重排序）、多 Agent 并发框架的搭建、调优与稳定性保障；
3. 深入理解 GPU 硬件特性（显存容量/带宽、算力、功耗墙、NVLink/PCIe 拓扑对推理的影响），建立"模型规模—量化方案—硬件配置—性能指标"的对应关系矩阵，让方案可预测、可复制。
三、行业方案与快速响应（约 20%）：
1. 快速理解各行业（政企、金融、医疗、教育、制造等）对本地模型的差异化需求（数据合规、知识库形态、并发量、响应速度、行业术语等），输出有针对性的模型部署方案（模型选型+参数配置+硬件档位推荐）；
2. 搭建真实硬件环境完成 PoC 验证与交付，现场调试优化软件环境，稳定高效地输出本地 AI 算力，解决用户实际需求；
3. 沉淀部署方案模板、调优手册与常见问题库，支持售前与交付团队。
【任职要求】
1. 熟悉桌面级和工作站级的CPU、主板、GPU和内存硬件各种型号，有本地AI部署工程落地经验；
2. 精通 Linux 系统与 NVIDIA GPU 生态（CUDA、驱动、显存管理），熟悉消费级/工作站级显卡的硬件特性与性能边界；
3. 熟练掌握至少一种推理框架（vLLM / TensorRT-LLM / SGLang / llama.cpp），有27- 70B 级模型的本地部署与性能调优实操经验，能通过参数与配置优化显著提升吞吐、降低 TTFT；
4. 熟悉模型量化技术及其对精度、显存、速度的影响，能根据硬件档位做出合理的量化与配置决策；
5. 熟悉 RAG 与知识库技术栈（Embedding 模型、向量数据库、LangChain / LlamaIndex 等）；
6. 熟悉整机压力测试方法与工具（GPU 压测、显存测试、长时间稳定性、功耗/噪音测试），有测试报告输出经验；
7. 具备强烈的"需求转方案"能力：能快速听懂行业客户的业务语言，拆解为技术指标，并在真实硬件上快速拿出可运行的方案；
8. 工作主动，能适应初创公司多任务并行与快速响应的节奏，具备良好的供应商沟通与文档能力；
9. 英雄不问来路，无学历要求，能者上。
