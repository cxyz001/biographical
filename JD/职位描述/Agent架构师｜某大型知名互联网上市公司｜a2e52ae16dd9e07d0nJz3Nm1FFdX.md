## 职位描述

岗位职责
1. Agent 基础设施总体架构：作为技术负责人，主导公司级 LLM Agent 基础设施的架构设计与技术规划，覆盖请求接入、上下文管理、模型推理、工具调⽤编排、任务执⾏的端到端架构，制定⽀撑多条业务线、日均千万级以上调用的整体技术蓝图与演进路线。
2. 推理服务架构与技术决策：主导 LLM 推理层的架构设计与选型决策（vLLM / TensorRT-LLM / SGLang / ⾃研框架），规划 KV Cache 优化、批处理调度（Continuous Batching / Chunked Prefill）、PD 分离、投机解码、模型量化蒸馏等关键技术路线，制定容量规划与算力伸缩策略，保障大规模推理服务的延迟、吞吐与稳定性。
3. Agent 运行时架构：设计高并发 Agent 运行时框架的整体架构，包括并发调度、结果缓存、短路求值、流式返回、上下文压缩、长任务异步执行与断点恢复等核心机制，定义 Agent 与工具生态（Function Calling / MCP 协议 / Tools / Skills）的集成规范，支撑复杂多步任务的高效稳定执行。
4. 高可用与稳定性体系：主导 Agent 系统的稳定性架构，设计全链路可观测体系（Tracing / Token 成本监控 / 慢调用分析）、限流熔断、分级降级（模型故障切换、多级兜底）、混沌演练机制，制定并守护 SLO 标准，对大规模生产环境的可用性负最终技术责任。
5. 成本架构与资源效率：建立公司级推理成本治理体系，规划模型分级路由（大小模型协同）、语义缓存复用、请求合并、批处理调度、GPU 资源池化与算力调度策略，在保障业务体验的前提下持续优化单位业务产出的算力成本，形成可复制的成本优化方法论。
6. 跨团队技术对齐与影响力：与算法、业务、平台等多方团队协同，主导关键技术方案的评审与决策，识别技术风险并制定预案；沉淀架构规范与技术文档，通过技术分享、方案评审等方式提升团队整体工程水平，培养骨干工程师。
任职要求
1. 本科及以上学历，计算机科学、软件工程、人工智能等相关专业。
2. 5 年以上后端 / 基础设施 / AI Infra 研发经验，其中 3 年以上架构师或 Tech Lead 经验，主导过至少一个支撑日均千万级调用（或同等规模）的大型在线系统或推理服务的架构设计与演进，有从 0 到 1 搭建并演进至大规模的完整经历。
3. 深度掌握 LLM 推理技术栈：深入理解 Transformer 推理机制与主流推理框架（vLLM / SGLang / TensorRT-LLM 至少一种）的架构原理，熟悉 KV Cache、批处理调度、量化（INT8 / FP8 / AWQ / GPTQ）、PD 分离、投机解码等关键技术的原理与落地权衡，能独立完成技术选型决策与容量规划。
4. 具备大规模分布式系统的架构纵深：精通高并发、异步编程、流式处理、缓存体系、消息队列、资源调度等核心工程范式，对容量规划、故障演练、灰度发布、降级容灾等稳定性体系有完整的方法论与实战经验。
5. 深入理解 LLM Agent 运行机制（Function Calling / MCP 协议 / 多步任务编排 / Multi-Agent 架构），能从架构视角识别 Agent 系统的性能与稳定性瓶颈，并设计体系化的解决方案而非单点优化。
6. 具备优秀的跨团队协作与技术推动能力，能在多方利益与约束下做出并守住技术决策；有带教团队、培养骨干的意愿与经验。
7. 对技术演进有前瞻判断：持续跟进推理加速、Agent 框架、算力调度等领域的前沿进展，能结合业务节奏制定务实的技术演进路线。
