## 职位描述

岗位职责：
1、参与业务需求的服务端技术方案设计、开发实现及持续迭代。
2、负责服务端代码测试、维护及线上问题排查。
3、参与数据库、缓存、消息队列、接口及服务部署方案设计。
任职要求：
1、3-5年服务端开发经验，具备扎实的计算机基础和良好的编码规范。
2、熟练掌握 Java、Go、Node.js 中至少一种及对应⽣态框架，如 Java/Spring Boot、Go/Gin 或 Kratos、Node.js/NestJS 或 Express；掌握两种及以上语⾔优先。
3、熟练部署和配置 Nginx，熟悉负载均衡、反向代理、rewrite 规则等配置；具备独⽴完成服务上线部署的经验。
4、熟悉 MySQL，熟练使用各类 DML，具备 SQL 与数据库配置优化能力；熟悉 Redis，能够熟练使⽤常用命令并完成缓存设计与问题排查。
5、熟悉 RESTful API / RPC 设计，理解高并发、分布式系统、缓存、幂等、消息可靠性及数据一致性等常见问题。
6、具备良好的沟通协作能力、责任心及线上故障排查能力。
7、熟悉 AI 辅助编程工具（如 Codex、Cursor 等），能够将其用于编码、测试及问题排查提效。
加分项：
具备性能优化、高扩展性架构设计经验者优先。
