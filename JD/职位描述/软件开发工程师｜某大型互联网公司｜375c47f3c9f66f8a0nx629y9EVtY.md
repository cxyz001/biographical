## 职位描述

面向机器狗智能巡检场景，参与平台业务、设备通信、任务调度及系统集成开发。工作覆盖软件功能实现、设备联调与项目现场交付，欢迎愿意深入实际业务和机器⼈应⽤的开发者。
岗位职责：
1.参与设备管理、地图与路线、巡检任务、告警及数据管理等业务功能的开发与维护。
2.根据项⽬需求完成业务逻辑、接口、数据处理及工具开发，能够适应不同技术栈并参与现有系统维护。
3.参与机器人及配套设备接⼊，实现状态上报、任务下发、实时消息处理，配合完成软硬件联调。
4.参与系统集成、部署验证及现场问题排查，配合项目实施与交付，编写必要的测试和技术文档。
5.将 AI 编程工具融入日常开发，遵循项目规范完成代码审查、测试与联调，对交付质量负责。
岗位要求：
1.本科及以上学历，具备 1-3 年软件开发经验，参与过实际项目开发，能够独立完成常规业务功能。
2.熟练掌握至少一种主流编程语言，具备扎实的编程基础，理解常用数据结构、异常处理与并发基础。
3.熟悉所用语言的常见开发框架，具备接口或服务开发经验，了解分层设计、网络通信与 RESTful API。
4.熟悉 MySQL 等关系型数据库，能够编写常用 SQL，了解索引、事务与分页；了解 ORM 和 Redis 的基础应用。
5.熟悉 Git，具备基本的 Linux 操作、日志分析和问题定位能力。
6.AI 编程能力（硬性要求）：熟练使用至少一种 AI 编程工具，如 Codex、Claude Code 或 Cursor，并有实际项目应用经验。能够结合代码上下文拆解需求，辅助完成编码、测试与问题排查，并审查和验证生成代码。面试需展示实际案例，完成 AI 辅助编程实操。
7.具备良好的沟通与协作能力，能够理解业务需求，主动推进开发、联调和问题闭环。
8.可接受因项目实施、设备联调及交付需要安排的出差，愿意学习机器人与物联网相关技术。
硬性条件：需要具备基本的网络调试能力，有过硬件设备调试经验优先。
加分项：
使用过 Vue / Element UI、MQTT / WebSocket、Docker / MinIO / Nacos；具备自动化工具或脚本开发经验；参与过机器人、物联网或工业软件项目；接触过 Three.js、点云可视化、OpenTCS 或 ROS。以上均为加分项，可入职后逐步学习。
项目技术栈与成长机会：
现有项目使用 Java / Spring Boot、Python、Vue、MySQL、Redis、MQTT、WebSocket 和 Docker 等技术，候选人开发语言不限。参与从平台管理到设备执行的完整业务流程，积累业务开发、设备通信、实时数据处理和系统集成经验。
