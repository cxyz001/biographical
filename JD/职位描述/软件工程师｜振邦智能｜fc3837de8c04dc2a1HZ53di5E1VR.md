## 职位描述

职位描述：
1.负责显示芯片 SDK 的需求分析、代码编写、调试、版本迭代与维护，完成 SDK 功能验证与性能优化。
2.提供芯片应用端技术支持，开展软硬件故障复现、定位、根因分析，输出故障分析报告。
3.编写设计文档、接口说明、用户手册、测试报告等各类技术文档，保证文档完整准确，同步版本更新。
4.对接内部业务以及外部客户，协助客户定位、解决产品开发及量产阶段遇到的芯片、驱动、显示相关问题，提供技术方案建议。
5.负责 OLED、TFT 显示模组驱动调试，熟练完成 MIPI、SPI、IIC 等通信接口的驱动开发、通信问题排查，解决花屏、闪屏、显示异常等各类显示问题。
6.跟进芯片新版本迭代，适配新硬件版本，完成回归测试；参与技术评审，输出改进建议，持续优化软件方案。
7.配合硬件团队开展软硬件联合调试，参与问题闭环，推动问题高效解决。
任职要求：
1.品行端正，具备良好的职业道德，工作认真踏实，责任心、学习进取心强；具备优秀的团队协作意识，沟通表达能力良好，能够跨团队协同推进问题。
2.本科及以上学历，电子、自动化、计算机、微电子、通信等相关专业；显示芯片 / 显示驱动方向 1 年及以上嵌入式软件开发工作经验。
3.熟练掌握 C 语言编程，具备完整的嵌入式项目开发实战经验，熟悉代码版本管理工具 Git/SVN。
4.精通嵌入式软件开发流程，熟悉 ARM 体系架构，了解 MCU、RTOS 实时操作系统原理与使用。
5.优先条件：具备 Bootloader、Firmware 固件开发、移植、调试经验；有芯片 SDK 开发、芯片验证、芯片测试、单片机开发项目经验优先。
6.能够独立使用示波器、逻辑分析仪、万用表等硬件测试仪器定位接口通信、电气相关问题；会使用 Layout 相关软件，能够看懂硬件原理图、PCB 版图。
7.扎实的软硬件综合基础，优秀的逻辑分析、问题排查能力，能够独立复现、拆解复杂疑难故障。
8.能够承受项目节点压力，主动推进问题闭环，有显示驱动、显示芯片行业项目经历者优先。
