## 职位描述

岗位定位
独立负责 AI Agent 运行时与应用层的核心模块设计与实现，把 Agent 从 demo 推到⽣产可⽤、可观测、可迭代。这是⼀个深度模块 Owner 岗位，不是全栈杂食岗。
岗位职责
Agent 核心机制：多 Agent 调度、状态机控制、上下⽂与状态管理、工具编排（Function Calling / Tool Use）、异常恢复与幂等重试、死循环与超时防护。
平台能力模块：可复用 Skill 体系、持续运行的感知—决策回路（Loop）、分层记忆体管理、检索增强（RAG / 向量检索 / 知识组织）。
性能与稳定性：流式输出链路、推理与检索延迟优化、Token 成本控制、并发与限流设计。
可观测与质量评估：全链路 tracing、失败归因、离线与在线评测集建设，打通「人工纠正 → 评测 → 策略/模型改进」的数据闭环。
技术选型与验证：持续跟踪 Agent 架构、工具调用协议、记忆机制等前沿方向，用最小实验验证可行性边界并给出明确结论。
任职要求
必须满足
本科及以上，计算机、软件工程、人工智能等相关专业；硕士优先。
4 年以上后端或 AI 工程开发经验，精通 Python（Go 加分），具备扎实的系统设计与工程实现能力。
