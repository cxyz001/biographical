## 职位描述

【关于此职位】
我们正在寻找一位资深全栈工程师，您要精通 TypeScript/JavaScript，能够构建从 Node.js 后端到浏览器的端到端稳健系统。这首先是一个“构建者”角⾊。我们已经拥有强⼤的⽹页设计师；我们需要的是能够设计架构，并将其转化为可运行、高韧性、⽣产级软件的人。
您将负责内部平台与服务的技术设计和交付，重点关注卓越运营、架构严谨性和动手构建能力。
【主要岗位职责】
•	主导我们旗舰产品的重大升级，该产品当前使用 Adonis 和 Lucid（基于 JavaScript 和 TypeScript）构建，并采用 Nuxt 和 Vue 作为前端。
•	设计数据库架构，管理多个 Azure 数据库。
•	设计并构建 CI/CD、容器化和云基础设施。
•	构建并维护开发与部署环境。
•	领导小型团队（2-5 名工程师）的技术交付工作：包括设计评审、软件开发生命周期标准、事故复盘，以及与内外部利益相关者的协调。
【任职资格】
•	扎实的 Node.js 后端经验，熟悉 AdonisJS 及 Lucid（或类似的 JavaScript 后端框架与 ORM 建模工具），能够构建 API 和服务——包括 REST、WebSockets 及服务间通信。
•	精通最新版本的 Vue 和 Nuxt（或类似的 JavaScript 前端框架）。
•	熟悉 JS/TS 生态系统中的自动化测试（例如 Jest/Vitest、Cypress/Playwright）。
•	扎实的 MS-SQL 经验——包括数据库设计、索引和缓存层；有 Azure 云服务经验者优先。
•	具备缓存的工作知识。
•	能够构建和设计 CI/CD 流水线。
•	具备 DevOps 经验。
•	拥有技术领导力的记录：负责过架构设计、主导设计评审、推动开发生命周期，并在团队内确保质量标准。
【加分项】
•	有构建 AI Agent / 大语言模型（LLM）驱动功能的经验——例如编排平台、RAG 流水线、图像处理、提示词工程，以及日常使用 AI 编程助手。
•	具有身份平台经验（SSO、OAuth 2.0、JWT、RBAC）。
•	拥有电商、零售、物流、供应链或 ERP/WMS 系统的领域经验。
•	有与全球/分布式团队及海外利益相关者合作的经验；具备优秀的英文沟通能力。
