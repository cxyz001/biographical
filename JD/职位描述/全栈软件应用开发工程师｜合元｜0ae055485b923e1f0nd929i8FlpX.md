1. 负责 Web 应用的前后端功能设计、开发、测试与维护。

4. 熟悉 HTML、CSS、JavaScript，能独立完成常见 Web 页⾯和后台管理界面开发。

6. 熟悉 Node.js，具备 `Express`、`WebSocket`、`JWT`、`pg` 等开发经验优先。
7. 熟悉 Web 应用基础能力，包括用户认证、权限控制、OAuth2、Session、CORS、文件上传下载等。
8. 理解 RESTful API 设计、前后端分离、异步处理、服务分层和模块化开发。
9. 具备良好的代码质量意识，重视可维护性、异常处理、日志记录和边界场景覆盖。
