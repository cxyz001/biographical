岗位职责
一、AI Native 研发流革新（核心差异化）
方向：以 Claude Code & Codex 联合应用为支点，把研发效率推到传统模式的数倍。
终端自动化流构建：深度集成 Claude Code 智能代理，利用其终端 / 命令行交互、跨文件多点修改、自动运行单测与回归等能力，把 Bug 修复、模块重构、脚手架搭建做成可复用的自动化工作流，而非一次性的「问答式编程」。
人机协作规范建设：编写并持续维护项目专属 CLAUDE.md 规范、自定义 Slash Command 与 Git Hooks，约束并引导 AI Agent 在本地安全、合规地实现充提、签名算法、清结算逻辑与前端交互层——让 AI 产出可控、可审计、可回滚。
AI 驱动的代码资产审计：结合 Codex 及演进版大模型的代码解析能力，针对钱包合约调用、冷热钱包资金归集、高并发清结算系统，建立自动化安全漏洞扫描 + 资金逻辑校对机制，把「资金安全」前置到编码阶段。
MCP 能力扩展：探索通过 MCP（Model Context Protocol）将内部知识库、链上数据与账务系统接入 AI 编码工具，定制专属于本业务的 AI 编码能力边界。
团队赋能：沉淀团队级 AI 协作最佳实践与模板，带动其他工程师把 AI 用到日常研发中。
二、区块链钱包与全栈核心开发
方向：以「资金零差错」为底线，独立扛起从链上交互到前端交互的全链路核心模块。
钱包核心模块：负责多币种钱包的地址生成与派生、交易构造与签名、充提币、跨链桥、冷热钱包资金归集与流转等核心模块开发，对每一笔资金的流向与状态机负责。
清结算与账务系统：搭建高并发、低延迟、强一致的清结算与资金账务系统，设计资金账本、对账与轧差逻辑，保证账目在异常、并发、回滚场景下的最终一致性与可审计。
链上交互底层攻坚：处理 RPC 节点交互异常与多节点容灾、交易拥堵与重发（替换 / 加速）、Nonce 管理、Gas Fee 动态预测、链重组与确认数策略等核心技术难题，保障链上链路在网络抖动下依旧稳健。
密钥与资金安全：把资金安全前置到架构设计，而非事后补丁——设计签名与审批的权限边界、密钥的生成 / 存储 / 使用全生命周期管控、大额出金的多重校验与熔断兜底。
全栈交互层：构建安全、流畅、低误操作的资金交互体验，做好二次确认、风险提示、地址校验与防错设计，让「点错一下」不会造成资金损失。
质量与稳定性：为关键资金路径编写充分的单测 / 集成测试与自动化对账机制，要求可复现、可回归、可灰度；建立异常监控与告警，对最终运行结果与资产安全绝对负责。
