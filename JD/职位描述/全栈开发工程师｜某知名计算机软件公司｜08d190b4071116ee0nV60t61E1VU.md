## 职位描述

我们是青风音乐（深圳）有限公司，专注 AI 科技+音乐内容生产。我们正在搭建一套基于⽣成式 AI 的⾳乐创作与管理系统，⽬标是将第三方音乐⽣成模型（如 Suno 或同类平台）与公司自有的音乐版权库、原声素材和风格数据进行整合，形成可管理、可训练、可商业化使用的 AI 音乐生产体系。
【岗位职责】
1. 对接并集成音乐生成类 API
    接入并管理第三方音乐生成模型（如 Suno 或同类工具）
    设计调用逻辑与生成参数控制（风格、情绪、节奏、结构等）
2. 搭建自有音乐资产管理系统
   管理公司自有曲库、原声素材、stem、sample
   建立标签体系（风格 / BPM / 情绪 / 使用场景等）
3. 模型训练 / 微调 / 条件化生成
   基于自有音乐数据，对生成模型（人声）进行训练、微调或条件约束
   提升生成内容与公司音乐风格的一致性和可控性
4. AI 音乐生成工作流设计
   设计从素材 → 生成 → 试听 → 筛选 → 输出的完整流程
   支持内部团队（A&R、制作、版权）使用
5. 跨团队协作
   与音乐制作人、A&R、产品团队沟通需求
   将创意需求转化为可实现的技术方案
【任职要求】
1、熟练使用 Python，有实际工程开发经验
2、有 API 集成经验（第三方服务、模型接口等）
3、理解机器学习\生成式 AI 的基本原理
4、能独立完成从需求到落地的系统开发
5、逻辑清晰，具备良好的文档和沟通能力
