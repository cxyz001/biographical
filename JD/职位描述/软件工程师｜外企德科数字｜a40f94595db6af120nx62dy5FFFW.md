## 职位描述

岗位职责：
1、参与业务需求讨论与梳理，理解业务流程、规则和边界，完成技术方案、数据库模型及接口设计，合理评估工作量。
2、基于 Java、Spring Boot 等技术开展后端业务开发，独立完成业务模块、RESTful API、权限控制、数据处理及第三方系统对接。
3、负责 MySQL\PostgreSQL 等关系型数据库设计与 SQL 优化，合理使⽤ Redis 缓存；根据业务需要处理事务⼀致性、接口幂等、并发及异步任务。
4、编写单元测试与必要的集成测试，参与代码审查，维护接口⽂档及部署说明；配合前端、测试和实施人员完成联调、发布及验收。
5、承担系统日常维护与线上问题排查，通过⽇志、监控及性能分析定位故障，持续改进系统性能、安全性、稳定性和可维护性。
6、合理使用 AI 编程工具辅助代码理解、开发、重构、测试与文档编写，对生成结果进行人工审查和测试验证，并沉淀可复用的实践经验。
任职条件：
1、计算机、软件工程等相关专业本科及以上学历，3 年及以上 Java 后端开发经验，有实际业务系统从需求到上线的完整交付经历，能够独立负责业务模块。
2、具备扎实的 Java 基础，熟悉面向对象、集合、异常处理、多线程与并发，理解 JVM 基本原理，具有良好的编码习惯和常用设计模式应用能力。
3、熟练使用 Spring Boot、Spring MVC、MyBatis 或 MyBatis-Plus，理解依赖注入、AOP 和事务机制，具备 RESTful API 设计与接口联调经验。
4、熟练使用 MySQL，掌握表结构设计、索引、事务及 SQL 优化；熟悉 Redis 常见使用场景，理解缓存失效、一致性及热点问题。
5、熟悉 HTTP、身份认证、权限控制和常见 Web 安全风险；具备接口幂等、异常处理及第三方系统集成经验。有消息队列或分布式系统实践经验者优先。
6、熟悉 Git、Maven、Linux 常用操作及日志排查，能够编写单元测试和维护接口文档；具有 Docker 部署、CI/CD 或性能调优经验者优先。
7、具备 AI 辅助编程的实际项目经验，熟练使用至少一种工具，如 GitHub Copilot、Cursor、Claude Code 或同类工具；能结合需求与代码上下文拆解任务，用于编码、重构、测试及故障分析，并说明具体案例与效果。
8、能够识别和验证 AI 生成代码中的逻辑错误、安全漏洞及无效依赖，不盲目采纳生成结果；遵守公司数据与代码保密规范，不向未经批准的平台提交敏感代码、客户数据或凭据。
9、具备良好的业务理解、逻辑分析、沟通协作和主动解决问题能力，有责任心，能够推动问题闭环并对交付质量负责。
