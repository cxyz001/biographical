## 职位描述

【关于我们】
A 股上市集团（侨银城市管理股份有限公司）控股的科技子公司——天奈人机交互技术（广州）有限责任公司。聚焦 AI + 城市服务，以自研多模态智能体平台落地智慧城市、市政环卫、社区服务等场景。你能主导核⼼ AI 项⽬的端到端闭环，以成熟智能体引擎为起点，拿真实的百城业务场景练⼿。
【这个岗位在做什么】
全栈交付，从后端到 AI 应用，整条链路不分家。不要求每项精通，但任一环节卡住，你能⾃己跨过去，而不是等别人来救。
1. AI 产品端到端闭环：从理解用户需求，到方案设计、编码落地、上线排错，主导核心项目交付。
2. 后端主干用 Java：我们服务的客户系统基础大多就是 Java 体系，你需要能直接衔接客户既有系统，用 Spring Boot / Spring Cloud 完成稳定交付。
3. AI 应用层用 Python：FastAPI 服务、RAG / 知识库链路、大模型与 Agent 编排，把 AI 真正做成能上线、能服务真实业务的产品。
4. 啃下让产品「能用」的硬骨头：数据库索引、内存泄漏、WebSocket 重连、SSE 流式输出这类问题。
5. 全链路使用 AI 编码工具：Cursor / Claude Code / Codex / Copilot / 通义灵码 等，至少深用两三个并形成自己的工作流——知道什么时候让 AI 写、什么时候自己写、什么时候让 AI 帮你 review。
【我们希望你】
1. 统招本科及以上，计算机、软件工程、电子信息或相关理工专业。
2. 3 年以上全栈开发经验，需来自真实业务项目中的持续交付（可说明项目规模与你的实际职责）。
3. Java 为基本语言（必备）：Spring Boot / Spring Cloud 具备架构级或主力开发经验，能直接嵌入客户既有技术体系。
4. Python 为 AI 应用层语言（必备）：能用 Python（FastAPI 等）完成 AI 应用与智能体开发；熟悉 MySQL / Redis / PostgreSQL。
5. 有 RAG / 知识库项目的实际落地经验（非 demo 级）：项目需已上线并服务真实业务，具备清晰的数据规模、并发量或业务指标。
6. 掌握 Docker、CI/CD，能完成云端部署与线上排错。
7. 前端 Vue3 / React + TypeScript，具备一定的了解，能借助 AI 工具完成常规开发即可，实际应用过更佳。
