## 职位描述

一、 职位描述
负责非标自动化设备中上位机软件的开发、调试与维护。
负责集成机器视觉系统（定位、测量、识别、检测等），完成相机选型、打光方案评估及视觉算法开发。
实现上位机与下位机（PLC、机器人、运动控制卡等）的通信和数据交互。
独立完成视觉项目的方案设计、程序编写、现场调试及验收文档编写。
解决项目在调试和运行过程中出现的软件及视觉相关技术问题。
二、 核心职责与技能要求
1. 上位机开发能力 (必需)
精通 C# 开发（WinForms 或 WPF），具备扎实的面向对象编程（OOP）思想。
熟练掌握多线程、串口（SerialPort）、网络通信（Socket/TCP/IP）、委托与事件等高级编程技术。
具备良好的数据库编程能力，能使用 SQL Server 或 MySQL 进行数据存储、查询和管理。
（加分项）了解或掌握其他语言如 Python、C++ 或 Java。
2. 机器视觉技术
精通至少一种主流视觉处理库，如 Halcon、VisionPro、OpenCV 等。（Halcon 和 VisionPro 在工业界更受欢迎）。
丰富的视觉项目实战经验，包括但不限于：
视觉定位（引导机械手抓取、对位贴合）
尺寸测量
字符识别（OCR）
缺陷检测
具备视觉硬件选型能力：熟悉主流品牌（如 Basler、Daheng、Hikvision 等）的相机、镜头、光源的特性及选型原则。
（加分项）有3D视觉（如线激光扫描）项目经验。
3. 工控通信与集成 (必需)
熟练掌握与下位设备通信的常用协议，如 Modbus (TCP/RTU)、OPC UA/DA、TCP/IP 自定义协议等。
有与主流PLC（西门子、三菱、欧姆龙等）、机械手（发那科、ABB、爱普生等）进行通信集成的实际项目经验。
（加分项）了解运动控制卡（如固高、雷赛）的二次开发。
4. 软技能与综合素质
具备优秀的分析问题和解决问题的能力，能承受工作压力，适应短期出差进行现场调试。
具备良好的技术文档编写能力（设计文档、调试记录、用户手册）。
具备良好的沟通能力和团队协作精神，能与机械、电气工程师紧密配合。
三、 加分项（非必需，但会极具竞争力）
有非标设备行业或产线自动化项目经验者优先。
了解基本的电气知识，能看懂电气原理图。
有UI/UX 设计经验，能开发出界面美观、交互流畅的上位机软件。
了解深度学习在视觉中的应用（如Halcon DL、VisionPro ViDi）。
四、 学历与经验
本科及以上学历，计算机、自动化、电气工程、机械电子等相关专业优先。
5年及以上相关岗位工作经验，有独立承担完整视觉项目经验者优先。
